Передаёт и загружает конфигурацию проекта с помощью Агента Rapid SCADA.

## Основные возможности

- Передаёт конфигурацию проекта через Агента.
- Загружает базу конфигурации, представления и выбранные настройки приложений.
- Использует параметры подключения и переноса из профиля развёртывания.
- Поддерживает фильтры объектов и исключение ключей регистрации при передаче.
- Показывает ход операции, поддерживает отмену и перезапускает выбранные службы после передачи.
