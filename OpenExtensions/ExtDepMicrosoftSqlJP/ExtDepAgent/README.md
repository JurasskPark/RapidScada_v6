Uploads and downloads project configuration using the Rapid SCADA Agent.

## Highlights

- Uploads project configuration through Agent.
- Downloads the configuration database, views and selected application settings.
- Uses the deployment profile's connection and transfer options.
- Supports object filters and registration-key exclusions during upload.
- Tracks progress, supports cancellation and restarts selected services after upload.
