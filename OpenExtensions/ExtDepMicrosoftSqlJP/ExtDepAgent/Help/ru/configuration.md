# ExtDepAgent — Настройка

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/configuration.md)

Расширение использует выбранный `DeploymentProfile`, а не отдельный файл настроек расширения.

- `AgentEnabled` должен быть включён; передача и загрузка отклоняют профиль с выключенным Агентом.
- `AgentConnectionOptions` содержит параметры подключения. Его `Timeout` также определяет тайм-аут управления службами.
- `UploadOptions` и `DownloadOptions` выбирают базу конфигурации (`IncludeBase`), файлы представлений (`IncludeView`), настройки Сервера (`IncludeServer`), Коммуникатора (`IncludeComm`) и Вебстанции (`IncludeWeb`).
- Настройки приложения включаются только тогда, когда оно включено в экземпляре проекта.
- При передаче `ObjectFilter` фильтрует данные каналов/представлений и связанные файлы, а `IgnoreRegKeys` исключает ключи регистрации.
- Перезапуск служб задаётся параметрами `RestartServer`, `RestartComm` и `RestartWeb` передачи.
