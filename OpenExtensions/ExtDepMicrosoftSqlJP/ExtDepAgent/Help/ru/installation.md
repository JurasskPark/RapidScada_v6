# ExtDepAgent — Установка

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/installation.md)

Используйте пакет для архитектуры Windows, в которой работает Администратор. Скопируйте `ExtDepAgent.dll` в `SCADA/ScadaAdmin/Lib`, языковые файлы — в `SCADA/ScadaAdmin/Lang`, согласно `release.json`.

Включите расширение `ExtDepAgent` в Администраторе. На целевом узле должен работать Агент Rapid SCADA, доступный через профиль развёртывания. Интерфейс настройки использует `net10.0-windows`.
