# ExtDepAgent — Использование

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/usage.md)

1. Выберите экземпляр проекта и профиль развёртывания в Администраторе.
2. Включите Агента и задайте параметры подключения.
3. Выберите разделы передачи/загрузки и, для передачи, параметры перезапуска служб.
4. Выполните соответствующую команду переноса проекта и следите за журналом операции.

Передача проверяет подключение к Агенту, упаковывает выбранную конфигурацию, передаёт её и применяет заданную политику перезапуска служб. Загрузка получает и распаковывает выбранные разделы. Интерфейс переноса разрешает отмену. Временные архивы удаляются после операции.
