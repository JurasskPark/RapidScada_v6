# ExtDepAgent — Installation

[Contents](index.md) · [Product](../../README.md) · [Русский](../ru/installation.md)

Use the package matching the Windows architecture of Administrator. Copy `ExtDepAgent.dll` to `SCADA/ScadaAdmin/Lib` and the language files to `SCADA/ScadaAdmin/Lang`, as specified in `release.json`.

Enable extension `ExtDepAgent` in Administrator. The destination must provide a running Rapid SCADA Agent accessible through the deployment profile. The configuration UI targets `net10.0-windows`.
