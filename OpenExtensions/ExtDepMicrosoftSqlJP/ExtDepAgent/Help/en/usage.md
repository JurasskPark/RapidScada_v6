# ExtDepAgent — Usage

[Contents](index.md) · [Product](../../README.md) · [Русский](../ru/usage.md)

1. Select the project instance and deployment profile in Administrator.
2. Enable Agent and configure its connection settings.
3. Choose upload/download sections and, for upload, service restart options.
4. Run the corresponding project transfer command and follow the progress log.

Upload tests the Agent connection, compresses selected configuration, transfers it and then applies the selected service restart policy. Download retrieves and extracts the selected sections. The transfer UI enables cancellation. Temporary archives are removed after the operation.
