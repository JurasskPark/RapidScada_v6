# MicrosoftSqlStorage — Usage

[Contents](index.md) · [Product](../../README.md) · [Русский](../ru/usage.md)

1. Prepare the `project` database schema and deploy configuration with ExtDepMicrosoftSqlJP.
2. Configure the instance's default database connection.
3. Select MicrosoftSqlStorage in the required applications.
4. Start those applications and inspect their logs for connection or missing-file errors.

The current repository contains the storage and deployment extension sources, but not the main application configuration editors. Exact outer XML configuration should follow the host version's storage configuration format.
