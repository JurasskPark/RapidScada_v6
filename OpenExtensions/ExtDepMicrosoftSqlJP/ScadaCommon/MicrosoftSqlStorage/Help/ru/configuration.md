# MicrosoftSqlStorage — Настройка

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/configuration.md)

Хранилище создаёт подключение Microsoft SQL Server из параметров подключения БД по умолчанию экземпляра, используя `KnownDBMS.MSSQL`.

`WaitTimeout` читается из XML-узла настройки хранилища как целое число секунд. Например:

```xml
<WaitTimeout>30</WaitTimeout>
```

При запуске попытки подключения выполняются в течение этого времени, с периодом попыток 10 секунд. Ошибки записываются в журнал приложения.

Разделители путей нормализуются к обратной косой черте. Это соглашение ключей в БД, которое не меняет платформу Linux-пакета.
