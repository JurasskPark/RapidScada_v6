# MicrosoftSqlStorage — Диагностика

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/troubleshooting.md)

- При ошибках подключения проверьте параметры БД экземпляра, доступность базы и права SQL-учётной записи.
- При ошибке отсутствующего файла проверьте развёртывание, идентификатор приложения и нормализованный путь.
- При отсутствии колонок базы конфигурации проверьте переданную схему. Для чтения таблицы нужна колонка первичного ключа; отсутствующие необязательные колонки пропускаются.
- При `PlatformNotSupportedException` SQL-клиента используйте пакет с конкретным идентификатором платформы и сохраните его зависимости.
- Архивные данные относятся к ModArcMicrosoftSqlJP, а не к этому хранилищу.
