# MicrosoftSqlStorage — Установка

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/installation.md)

Выберите пакет для конкретной ОС и архитектуры: `win-x64`, `win-x86` или `linux-x64`. AnyCPU ZIP не выпускается: исполняемая реализация SQL-клиента должна соответствовать хосту.

Пакет содержит файлы хранилища для `SCADA/ScadaServer`, `SCADA/ScadaComm` и `SCADA/ScadaWeb`. Сохраняйте комплектные зависимости SQL-клиента рядом с файлами хранилища. Включите `MicrosoftSqlStorage` в конфигурации каждого приложения, которое его использует.

Библиотека использует `net10.0`; хост Rapid SCADA должен работать на .NET 10. Подготовьте и передайте базу конфигурации через [ExtDepMicrosoftSqlJP](../../../../README.ru.md).
