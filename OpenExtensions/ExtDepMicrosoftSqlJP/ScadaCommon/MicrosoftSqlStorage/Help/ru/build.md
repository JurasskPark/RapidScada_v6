# MicrosoftSqlStorage — Сборка

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/build.md)

Из корня репозитория:

```cmd
Build-Release.bat -Project MicrosoftSqlStorage -Runtime win-x64
```

Нужны Windows, PowerShell 7.2+ и .NET 10 SDK. Платформы пакетов: `win-x64`, `win-x86`, `linux-x64`. Подробнее — в [инструкции упаковки](../../../../../../Help/ru/release-packaging.md).
