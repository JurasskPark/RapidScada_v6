# MicrosoftSqlStorage — Использование

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/usage.md)

1. Подготовьте схему БД `project` и передайте конфигурацию через ExtDepMicrosoftSqlJP.
2. Настройте подключение БД по умолчанию экземпляра.
3. Выберите MicrosoftSqlStorage в нужных приложениях.
4. Запустите приложения и проверьте журналы на ошибки подключения или отсутствующие файлы.

В этом репозитории есть исходники хранилища и расширения развёртывания, но нет редакторов конфигурации основных приложений. Внешний XML настройки должен соответствовать формату хранилищ используемой версии хоста.
