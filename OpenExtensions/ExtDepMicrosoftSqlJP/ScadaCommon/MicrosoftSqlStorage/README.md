Reads and writes Rapid SCADA configuration and view files in Microsoft SQL Server.

## Highlights

- Stores configuration database tables in the `project` schema.
- Reads and writes application configuration and storage files.
- Stores view files as binary data.
- Uses the instance's default Microsoft SQL Server connection settings.
- Supports an optional startup wait for database availability.
