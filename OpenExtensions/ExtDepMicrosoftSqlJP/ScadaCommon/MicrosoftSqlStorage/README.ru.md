Читает и записывает конфигурацию и файлы представлений Rapid SCADA в Microsoft SQL Server.

## Основные возможности

- Хранит таблицы базы конфигурации в схеме `project`.
- Читает и записывает файлы конфигурации и хранилища приложений.
- Хранит файлы представлений в двоичном виде.
- Использует подключение Microsoft SQL Server по умолчанию из экземпляра.
- Поддерживает ожидание доступности БД при запуске.
