# PlgMimDisplayJP — Механический счётчик

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/mechanical-counter.md)

`MechanicalCounter` показывает конечное значение канала фиксированными числовыми барабанами. Он не интегрирует расход и не вычисляет накопленный итог: нужное значение предоставляет исходный канал.

| Параметр | По умолчанию / диапазон | Назначение |
| --- | --- | --- |
| `size` | 420 × 150 пикселей | Начальные размеры |
| `inCnlNum` | 0 | Основной входной канал |
| `previewValue` | 1284.7 | Предпросмотр редактора |
| `digitCount` | 7 / 1–12 | Количество барабанов |
| `decimalPlaces` | 1 / 0–3 | Выделенные дробные барабаны |
| `leadingZeroes` | `true` | Заполнять свободные ведущие разряды нулями |
| `unitText` | Пусто | Подпись единицы; пустая единица не занимает место |
| `showCaption` | `true` | Показывать подпись счётчика |
| `captionText` | Пусто | Заменить локализованную подпись итога |
| `animateChanges` | `true` | Анимировать изменение барабанов |
| `animationDurationMs` | 350 / 100–1500 мс | Длительность перехода |
| `useCustomColors` | `false` | Включить пользовательские цвета |
| `digitColor` | `#f3f1e8` | Цифры |
| `panelColor` | `#202326` | Панель |
| `accentColor` | `#2d6f9f` | Дробные барабаны |

Последние `decimalPlaces` барабанов имеют акцентный фон; десятичная точка не рисуется. Рамка, отступы, промежутки, барабаны, подпись и единица масштабируются вместе. Настройка уменьшения движения отключает анимацию барабанов. Плохие/отсутствующие данные и переполнение остаются прочерками, в том числе при включённых ведущих нулях. См. [форматирование](numeric-format.md).
