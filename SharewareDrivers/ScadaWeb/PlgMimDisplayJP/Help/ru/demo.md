# PlgMimDisplayJP — Автономная демонстрация

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/demo.md)

`DisplayDemo` — один сохраняемый компонент с шестью внутренними образцами табло. Он работает без серверной лицензии компонента и не имеет живых привязок каналов, скриптов, действий ячеек или реальных API оператора.

В редакторе он показывает статичный английский предпросмотр. Перемещение, изменение размера, копирование, удаление и сохранение используют обычные операции Mimic. Из сохранённого документа принимаются только свойства оболочки: идентификация, положение/размер, видимость, включённость и подсказка. Начальный размер — 960 × 1070 пикселей.

При исполнении каждый экземпляр запускает собственное локальное моделирование. Изменение уровня обновляет числовые индикаторы, накопительный счётчик, уровень/температуру таблицы и условный текст. Каждый образец показывает свой искусственный вход и качество.

Локальные элементы управления меняют уровень **0–100%**, качество, стиль сегментного табло и текст строки. Переопределения сохраняются между тиками таймера до сброса либо возврата соответствующего переключателя в автоматический режим. Автоматический цикл показывает три сегментных стиля, хорошее/плохое/отсутствующее качество, движение барабанов, прокрутку и условные цвета. Введённые и сгенерированные значения не сохраняются.

Подписи демо по умолчанию английские даже при русском хосте; фразы EN/RU берутся из словарей плагина. Подписи палитры следуют языку хоста. Длинный текст строки переносится рядом с образцом; неизменившийся текст не перезапускает анимацию при каждом обновлении числа.

У каждого экземпляра один таймер. Удаление, отключение, скрытие, переход в редактор или удаление родительского DOM-узла освобождают таймер и анимации отрисовки. Копии имеют независимое состояние. Уменьшение движения отключает анимацию, но искусственные показания продолжают обновляться.

[Галерея PNG](screenshots.md) показывает отдельные локальные примеры хоста. Их дополнительные тестовые элементы управления относятся к этим схемам и не входят в компоненты только для чтения или `DisplayDemo`.
