# PlgMimDisplayJP — Бегущая строка

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/marquee-display.md)

`MarqueeDisplay` — панель произвольного текста канала только для чтения. Она использует форматированный хостом вход и не ограничивает значение числовыми разрядами.

| Параметр | По умолчанию / диапазон | Назначение |
| --- | --- | --- |
| `size` | 360 × 64 пикселя | Начальные размеры |
| `inCnlNum` | 0 | Основной входной канал |
| `previewText` | Двуязычный пример готовности системы | Текст только для редактора |
| `noDataText` | `#.#` | Заглушка плохих/отсутствующих данных |
| `displayColor` | `#ffb43c` | Цвет текста |
| `panelColor` | `#160d02` | Цвет панели |
| `scrollEnabled` | `true` | Разрешить прокрутку |
| `direction` | `Left` / `Left`, `Right` | Направление прокрутки |
| `speed` | 45 / 10–200 пикселей/с | Скорость прокрутки |
| `pauseSeconds` | 1 / 0–10 с | Пауза между циклами |

Исходный текст предпросмотра — `SYSTEM READY • СИСТЕМА ГОТОВА`. Прокрутка начинается только при пригодных данных во время исполнения и переполнении панели текстом. Режим редактора, плохие/отсутствующие данные и уменьшение движения оставляют строку неподвижной. Короткий неподвижный текст центрируется; длинный начинается от левого края. Неизвестное направление заменяется на `Left`.

Рамка, отступы, текст и промежуток повторной прокрутки масштабируются по фактическим размерам. Текст из нескольких записей поддерживается через длину объединения основного входа; см. [каналы](channels.md).
