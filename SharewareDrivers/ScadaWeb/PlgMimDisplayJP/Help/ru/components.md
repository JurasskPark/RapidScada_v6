# PlgMimDisplayJP — Каталог компонентов и параметры

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/components.md)

Обычная палитра содержит шесть типов. Постоянные имена типов сохраняются на обоих языках.

| Тип | Назначение | Настройки |
| --- | --- | --- |
| `SegmentDisplay` | Сегментные, текстовые светодиодные и ЖК-панели | [Справочник](segment-display.md) |
| `DotMatrixDisplay` | Матричные цифры с подписями качества | [Справочник](dot-matrix-display.md) |
| `MechanicalCounter` | Числовые барабаны и дробная точность | [Справочник](mechanical-counter.md) |
| `MarqueeDisplay` | Произвольный текст и прокрутка при переполнении | [Справочник](marquee-display.md) |
| `DataTableDisplay` | Объединённые ячейки, измерения и действия | [Справочник](data-table-display.md) |
| `ValueTextDisplay` | Упорядоченные правила значений, текст и цвета | [Справочник](value-text-display.md) |

Независимое [DisplayDemo](demo.md) использует внутренние образцы всех шести типов. Общие справочники: [форматирование чисел](numeric-format.md), [каналы и качество](channels.md), [ячейки таблицы](table-cells.md), [действия](actions.md) и [правила значений](rules.md).

Свойства стандартных компонентов Mimic сохраняют контракты хоста. Четыре индикатора только для чтения намеренно скрывают интерактивные свойства и общее оформление; гибкая таблица и условный текст имеют контракты, описанные на своих страницах.
