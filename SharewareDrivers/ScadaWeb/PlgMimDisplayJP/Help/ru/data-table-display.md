# PlgMimDisplayJP — Таблица данных

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/data-table-display.md)

`DataTableDisplay` хранит списки относительных `rows`, `columns` и размещённых `cells`. Жёсткого предела количества элементов нет; практический размер зависит от браузера и схемы. Ячейки поддерживают объединение строк/столбцов, текст, значения, упорядоченные правила, подписи, единицы и изображения Mimic.

| Параметр | По умолчанию / диапазон | Назначение |
| --- | --- | --- |
| `size` | 260 × 180 пикселей | Начальные размеры |
| `rows`, `columns` | По две равные полосы | Относительные размеры сетки |
| `cells` | Заголовок и две ячейки строки данных | Начальное расположение |
| `cellPadding` | Сверху/снизу 4, слева/справа 6 пикселей | Основные внутренние отступы |
| `defaultTextDirection` | `Horizontal` | Основное направление текста |
| `defaultTextAlign` | `MiddleLeft` | Основное выравнивание |
| `defaultWordWrap` | `true` | Основной перенос строк |
| `showHorizontalLines`, `showVerticalLines` | `true` | Независимые разделители |
| `gridLineWidth` | 1 пиксель / редактор 0–12 | Ширина разделителя; чтение сохраняет неотрицательные значения |
| `gridLineColor` | `#667085` | Цвет разделителя |
| `backColor`, `foreColor` | `#344054`, `#e5e7eb` | Основные фон/текст |
| `border` | Ширина 1 пиксель, цвет `#667085` | Внешняя рамка |
| `showTrendSelection` | `true` | Маркеры выбора каналов |
| `trendButtonText` | Локализованная подпись графика | Общая кнопка графика |
| `trendChartArgs` | Пусто | Аргументы графика выбранных каналов |

Координаты ячеек начинаются с **1**. Ячейки за границами сетки и пересечения пропускаются; область занимает первая настроенная ячейка. Объединение должно полностью помещаться в сетке. Внешний контур задаёт стандартная рамка компонента независимо от горизонтальных/вертикальных разделителей.

Основные `inCnlNum` и `outCnlNum` таблицы равны нулю, основное `clickAction` пустое. Привязки и [действия](actions.md) относятся к [ячейкам](table-cells.md). Явно сохранённый пустой список ячеек остаётся пустым и не восстанавливает начальные ячейки.
