# PlgMimDisplayJP — Правила текста по значению

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/rules.md)

`ValueTextRule` наследует стандартное условие Mimic из двух сравнений и добавляет `text`, `foreColor`, `backColor` и `imageName`. Список упорядочен и не имеет жёсткого предела количества правил: побеждает первое выполненное.

| Поле | Назначение |
| --- | --- |
| `comparisonOper1`, `comparisonArg1` | Первое сравнение и числовой аргумент |
| `logicalOper` | `And` или `Or` для двух сравнений |
| `comparisonOper2`, `comparisonArg2` | Необязательное второе сравнение |
| `text` | Текст при совпадении |
| `foreColor`, `backColor` | Цвета при совпадении |
| `imageName` | Изображение Mimic при совпадении |

Идентификаторы сравнений: `None`, `Equal`, `NotEqual`, `LessThan`, `LessThanEqual`, `GreaterThan` и `GreaterThanEqual`. Одно сравнение задаёт точное значение, два — диапазон. Неиспользуемое второе сравнение оставляйте `None`.

Специфичные случаи размещайте раньше широких диапазонов. У `ValueTextDisplay` отсутствие совпадения использует состояние по умолчанию, плохой/отсутствующий вход — состояние отсутствия данных. У ячеек `ValueText` отсутствие совпадения использует `text` ячейки; непригодный вход — `noDataText`.

Пустое совпавшее текстовое или визуальное поле заменяется настроенным значением компонента/ячейки. Правила меняют представление, а не записывают в каналы. Минимальный пример диапазонов приведён в [примерах](examples.md).
