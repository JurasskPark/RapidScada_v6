# PlgMimDisplayJP — Активация

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/activation.md)

Исполнение обычных компонентов использует проверку LicenseJPLite для точного имени приложения **PlgMimDisplayJP**. Наличия файла недостаточно: проверяются подпись, идентификатор сервера, срок действия и принадлежность продукту.

| Объект | Имя / расположение |
| --- | --- |
| Файл лицензии | `PlgMimDisplayJP_License.bin` |
| Запрос активации | `PlgMimDisplayJP_Activation.bin` |
| Каталог стандартного хоста | `AppDirs.ConfigDir` работающей Вебстанции |
| Контракт провайдера | Версия 1 |

1. Установите полный пакет исполнения и включите плагин.
2. Запустите Вебстанцию. При отсутствующей или неверной лицензии и доступной LicenseJPLite плагин подготовит запрос активации в каталоге конфигурации.
3. Передайте запрос именно этого продукта через согласованный канал выдачи лицензии.
4. Поместите выданный `PlgMimDisplayJP_License.bin` в каталог конфигурации работающего хоста.
5. Перезапустите Вебстанцию и проверьте сообщение о лицензии плагина.

Журнал сервера фиксирует результат проверки. Коды состояния: `valid`, `missing`, `invalid` и `error`. Ошибка создания запроса выводится вместе с ошибкой проверки; проверьте доступ к каталогу и полный комплект LicenseJPLite. Существующий запрос сохраняется.

Лицензия `Single` остаётся привязанной к серверу. Редактору не нужна вторая локальная лицензия компонента. Лицензии другого плагина этот продукт не включают. Цена, контакты выдачи и дополнительные коммерческие условия в изученных материалах не указаны; используйте предоставленные сведения о покупке.
