# PlgMimDisplayJP — Каналы и качество данных

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/channels.md)

`SegmentDisplay`, `DotMatrixDisplay`, `MechanicalCounter` и `ValueTextDisplay` используют конечное исходное числовое значение. `MarqueeDisplay` получает форматированный хостом текст входа и может показывать произвольный текст.

Основной вход определяется положительным номером привязанного `inCnlNum`, иначе — свойством компонента `inCnlNum`. Отсутствие положительного номера означает отсутствие данных. Запись должна относиться к запрошенному каналу; `stat > 0` означает пригодное качество. Для числовых табло дополнительно требуется конечное число.

Чтение основного входа учитывает `InCnlProps.JoinLen` через `inCnlProps.joinLen`, поэтому текст Unicode/ASCII из нескольких восьмибайтовых записей не обрезается до первой записи. Скалярные каналы сохраняют штатную длину хоста. Ячейки таблицы читают собственные числовые каналы и получают автоматически создаваемые `propertyBindings` без повторов; изменение `cells` обновляет привязки.

| Состояние | Числовые индикаторы | Бегущая строка | Таблица / условный текст |
| --- | --- | --- | --- |
| Пригодные данные | Форматированное исходное число | Форматированный хостом текст | Значение канала или подходящее правило |
| Плохие данные или отсутствующий вход | Прочерки во всех разрядах | `noDataText` | `noDataText` ячейки или состояние отсутствия данных компонента |
| Переполнение числа | Прочерки без обрезки разрядов | Неприменимо | Нет фиксированного ограничения числовыми разрядами |
| Режим редактора | `previewValue` | `previewText` | Значение предпросмотра и настроенные правила |

Живые значения, форматированный текст, качество, выбор каналов и анимация временные и не сохраняются в XML мнемосхемы. При неверной серверной лицензии обычные компоненты вообще не обрабатывают свои входы; см. [лицензирование](license.md).
