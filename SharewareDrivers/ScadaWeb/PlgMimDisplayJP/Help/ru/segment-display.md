# PlgMimDisplayJP — Сегментный индикатор

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/segment-display.md)

`SegmentDisplay` — числовое табло только для чтения. `displayStyle` выбирается из `SevenSegment` (семь светодиодных сегментов), `LedText` (текст шрифтом Russo One) и `IndustrialLcd` (ЖК-панель). Все стили используют одинаковое форматирование чисел.

| Параметр | По умолчанию / диапазон | Назначение |
| --- | --- | --- |
| `size` | 300 × 96 пикселей | Начальные размеры |
| `displayStyle` | `SevenSegment` | Стиль отрисовки |
| `inCnlNum` | 0 | Основной входной канал |
| `previewValue` | 123.45 | Предпросмотр редактора |
| `digitCount` | 6 / 1–12 | Фиксированное число разрядов |
| `decimalPlaces` | 2 / 0–6 | Дробная точность |
| `unitText` | Пусто | Подпись единицы |
| `useCustomColors` | `false` | Использовать следующие цвета вместо палитры стиля |
| `displayColor` | `#59ff91` | Цифры |
| `panelColor` | `#07130d` | Панель |
| `showGlow` | `true` | Подсветка/свечение |

Неизвестное имя стиля заменяется на `SevenSegment`. Десятичная точка не занимает разряд, минус занимает. Плохие/отсутствующие данные и переполнение показываются прочерками. См. [форматирование чисел](numeric-format.md).
