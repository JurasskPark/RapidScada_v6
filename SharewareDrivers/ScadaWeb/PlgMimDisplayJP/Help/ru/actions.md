# PlgMimDisplayJP — Действия ячеек таблицы

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/actions.md)

`DisplayCellAction` содержит `name` и `icon` (необязательные), `actionType` (по умолчанию `DrawChart`), `inCnlNums`, `chartArgs`, `outCnlNum` (по умолчанию 0), `commandValue` (по умолчанию 0) и стандартные `linkArgs`. При пустом имени используется локализованная подпись действия. Неизвестные типы действий заменяются на `DrawChart`.

| Тип | Параметры | Результат |
| --- | --- | --- |
| `DrawChart` | `inCnlNums`, `chartArgs` | Открыть назначенный хостом график |
| `ShowCommand` | Положительный `outCnlNum` | Открыть диалог команды хоста |
| `SendCommand` | Положительный `outCnlNum`, конечное `commandValue` | Немедленно отправить числовую команду |
| `OpenLink` | `linkArgs` | Открыть представление или URL |

Пустой `inCnlNums` использует `inCnlNum` ячейки. Списки каналов принимают положительные числа и возрастающие диапазоны, например `101,102,110-112`; неверные и повторные элементы пропускаются. График использует назначенный Вебстанции `ChartFeature`, поэтому компонент не требует конкретного плагина графиков.

Немедленная отправка выполняется только явным `SendCommand`. `ShowCommand` открывает диалог. Обоим действиям команд нужны включённый компонент, права управления при исполнении, положительный выходной канал и соответствующий API хоста. `commandValue` — запрошенное значение, а не подтверждённая обратная связь канала. Действия ячеек **не содержат действия со скриптом**.

Обычное нажатие выполняет первое действие. Правая кнопка, клавиша меню или `Shift+F10` открывают все действия в настроенном порядке; клавиатурная активация — `Enter`/`Space`. В редакторе и при отключённом компоненте действия не выполняются.

Для общего графика включите `showTrendSelection` и отметьте ячейки `trendSelectable` с положительными входами. Выбор исключает повторы номеров и открывает список через запятую с `trendChartArgs`. Выбор временный.

`linkArgs` поддерживает положительный `viewID` или `url`, стандартную цель перехода, размер модального окна и параметры URL. Идентификатор представления имеет приоритет над URL. Переходам нужна навигация хоста; команды и графики также зависят от настройки Вебстанции.
