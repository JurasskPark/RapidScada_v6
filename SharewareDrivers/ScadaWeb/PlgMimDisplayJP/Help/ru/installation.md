# PlgMimDisplayJP — Установка

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/installation.md)

Устанавливайте полный пакет для своей ветки Rapid SCADA, сохраняя структуру каталога `SCADA`.

| Каталог назначения | Содержимое |
| --- | --- |
| `ScadaWeb/` | `PlgMimDisplayJP.dll`, подходящие зависимости и метаданные пакета |
| `ScadaWeb/lang/` | `PlgMimDisplayJP.en-GB.xml` и `PlgMimDisplayJP.ru-RU.xml` |
| `ScadaWeb/wwwroot/plugins/MimDisplayJP/` | JavaScript, CSS, значки и шрифт Russo One с `OFL.txt` |
| `ScadaAdmin/Lib/` | `PlgMimDisplayJP.View.dll` для Классического Администратора |

1. Остановите обновляемый экземпляр Вебстанции и скопируйте полный пакет в его установку SCADA.
2. Зарегистрируйте и включите `PlgMimDisplayJP` в конфигурации плагинов Вебстанции, затем передайте конфигурацию работающему хосту.
3. При использовании Классического Администратора установите подходящий модуль View на рабочую станцию редактора.
4. Установите [серверную лицензию](activation.md) для исполнения обычных компонентов.
5. Перезапустите Вебстанцию, повторно откройте редактор и обновите ресурсы браузера.

Сохраните зависимости LicenseJPLite, подходящую `PlgMimic.Common.dll` и генерируемый `js/zz-runtime-license.js`. Без ресурса защиты обычные типы не загружаются в нелицензированном режиме исполнения. Не подменяйте библиотеки ядра файлами другой ветки.

Базовый путь браузерных ресурсов — `/plugins/MimDisplayJP`. Соблюдайте регистр каталогов и файлов на соответствующих хостах. Браузерному редактору JP нужны собственные подходящие регистрация компонентов и пакет; копирование View DLL Классического Администратора его не устанавливает.
