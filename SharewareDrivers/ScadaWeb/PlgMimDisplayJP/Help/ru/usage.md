# PlgMimDisplayJP — Использование табло

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/usage.md)

1. Откройте мнемосхему в стандартном или совместимом редакторе JP.
2. Разместите компонент из палитры табло и задайте размер.
3. Выберите входной канал либо настройте вход каждой ячейки таблицы.
4. Значениями и текстом предпросмотра проверьте расположение и условные правила без живых данных.
5. Сохраните схему, передайте проект и откройте представление в Вебстанции.
6. Проверьте реальные значения входов, качество данных и серверную лицензию.

Значения предпросмотра редактора не являются командами или резервными живыми показаниями. При исполнении входные данные и качество определяются независимо. Успешное действие отправки команды не подменяет измеренную обратную связь.

Для графика таблицы выбирайте разрешённые ячейки их маркерами и открывайте общую кнопку графика. Нажатие ячейки выполняет первое настроенное действие; правая кнопка мыши, клавиша меню или `Shift+F10` открывает упорядоченное меню действий. Клавиатура также поддерживает активацию через `Enter`/`Space`. См. [действия](actions.md).

Неподвижная бегущая строка может работать правильно: короткий текст, режим редактора, плохие/отсутствующие данные, отключённая прокрутка и уменьшение движения запрещают прокрутку. Для автономного знакомства используйте [DisplayDemo](demo.md).
