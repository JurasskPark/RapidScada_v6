# PlgMimDisplayJP — Диагностика

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/troubleshooting.md)

| Симптом | Что проверить |
| --- | --- |
| В редакторе нет типов табло | Регистрацию плагина, подходящий пакет хоста/компонентов, словари и браузерные ресурсы |
| Обычные компоненты показывают предупреждение о лицензии при исполнении | Ключ точного продукта, каталог конфигурации работающего хоста, зависимости LicenseJPLite и журнал; перезапуск после замены |
| Числовая панель показывает прочерки | Положительный вход, запись/качество, конечное число, знак и количество разрядов после округления |
| Матрица показывает плохое качество или отсутствие данных | Качество и переполнение; предпросмотр редактора является отдельным состоянием |
| Бегущая строка не прокручивается | Пригодные данные при исполнении, реальное переполнение текстом, `scrollEnabled` и уменьшение движения |
| Длинный текст обрезается первой записью канала | Метаданные основного входа и `InCnlProps.JoinLen` |
| Ячейка таблицы отсутствует | Положение от единицы, полное объединение внутри сетки, более ранние пересечения; консоль браузера |
| Формат ячейки отличается от шаблона | При исполнении приоритет у `df.dispVal` хоста |
| Неверный условный текст | Порядок правил, границы сравнений, первое совпадение и состояние отсутствия данных |
| Не меняются цвет/шрифт ячейки | `useDefaultStyle`, наследование шрифта и переопределения правил |
| График не открывается | Положительный список входов, назначенный график, `trendSelectable` и включённость компонента |
| Действие команды неактивно | Явный тип действия, положительный выход, конечное немедленное значение, права управления и API хоста |
| Барабаны анимируются неожиданно или неподвижны | `animateChanges`, длительность перехода и настройку уменьшения движения |
| Нет оформления/шрифта | Полный каталог `/plugins/MimDisplayJP`, регистр и кэш браузера |

Проверьте сообщения плагина/локализации/лицензии в журнале Вебстанции, затем консоль и сетевые запросы браузера для неудачных загрузок ресурсов или пропущенных ячеек. Проверяйте полный пакет до замены отдельных зависимостей. Исполнение и редактор — разные контексты: правильный предпросмотр не подтверждает лицензированное живое табло.
