## Числовой индикатор напряжения

Разместите `SegmentDisplay` и задайте следующие свойства. Канал **101** условный: замените его реальным измеряемым входом проекта.

| Параметр | Значение |
| --- | --- |
| `inCnlNum` | 101 |
| `displayStyle` | `SevenSegment` |
| `digitCount` | 6 |
| `decimalPlaces` | 2 |
| `unitText` | `V` |
| `previewValue` | 230.15 |

Предпросмотр показывает 230.15 в редакторе; исполнение показывает вход 101. Выходной команды у индикатора нет.

## Условный текст уровня

Для `ValueTextDisplay` с условным входом **102** разместите три правила в следующем порядке. Переведите отображаемые подписи для проекта; идентификаторы условий сохраняются.

| Порядок | Поля условия | Текст |
| --- | --- | --- |
| 1 | `comparisonOper1 = LessThan`, `comparisonArg1 = 20` | Низкий |
| 2 | `comparisonOper1 = GreaterThanEqual`, `comparisonArg1 = 20`, `logicalOper = And`, `comparisonOper2 = LessThan`, `comparisonArg2 = 80` | Норма |
| 3 | `comparisonOper1 = GreaterThanEqual`, `comparisonArg1 = 80` | Высокий |

Задайте `defaultText` для пригодных значений без совпадения и `noDataText` для непригодных данных. Проверьте `previewValue` на 19, 20, 79 и 80; при исполнении используется канал, а не предпросмотр.

## Таблица из двух строк

Создайте две строки и два столбца с `size = 1`. Поместите заголовок `StaticText` в `row = 1`, `column = 1`, `columnSpan = 2`. Во второй строке поместите статичную подпись в столбец 1 и ячейку `ChannelValue` с условным входом **101** в столбец 2.

Включите `trendSelectable` ячейки значения и при необходимости добавьте действие `DrawChart`. Оставьте его `inCnlNums` пустым для использования входа ячейки. Выходной канал и действие команды не нужны. У хоста должен быть назначен график.
