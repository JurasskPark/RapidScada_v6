# PlgMimDisplayJP — Текст по значению

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/value-text-display.md)

`ValueTextDisplay` преобразует числовой вход в текст, цвета и дополнительное изображение Mimic. Сохраняются стандартные `inCnlNum` и одно `clickAction` компонента.

| Параметр | По умолчанию / диапазон | Назначение |
| --- | --- | --- |
| `size` | 150 × 56 пикселей | Начальные размеры |
| `inCnlNum` | 0 | Основной входной канал |
| `previewValue` | 1 | Предпросмотр редактора |
| `rules` | Одно правило: значение > 0 | Локализованный текст включения на зелёном фоне |
| `defaultText` | Локализованный текст выключения | Текст пригодного значения без совпадения |
| `baseForeColor` | `#ffffff` | Основной цвет текста |
| `baseBackColor` | `#475467` | Основной фон |
| `defaultImageName` | Пусто | Изображение по умолчанию/без совпадения |
| `noDataText` | `#.#` | Текст плохих/отсутствующих данных |
| `noDataForeColor` | `#fef2f2` | Цвет текста плохих/отсутствующих данных |
| `noDataBackColor` | `#991b1b` | Фон плохих/отсутствующих данных |
| `noDataImageName` | Пусто | Изображение плохих/отсутствующих данных |
| `padding` | Сверху/снизу 4, слева/справа 8 пикселей | Внутренние отступы |
| `textDirection` | `Horizontal` | Направление текста |
| `textAlign` | `MiddleCenter` | Выравнивание |
| `wordWrap` | `true` | Перенос строк |

Первое подходящее [правило](rules.md) побеждает. Пригодное значение без совпадения использует состояние по умолчанию; плохой/отсутствующий/неконечный вход — отдельное состояние отсутствия данных. Предпросмотр редактора вычисляет правила по `previewValue`.

Пустые поля правила заменяются значениями компонента. Переопределения `defaultForeColor`/`defaultBackColor` старых файлов продолжают читаться. Изменение `baseForeColor`/`baseBackColor` задаёт соответствующий основной цвет и очищает его прежнее переопределение.
