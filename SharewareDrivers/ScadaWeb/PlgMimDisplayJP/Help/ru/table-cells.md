# PlgMimDisplayJP — Ячейки и размеры таблицы

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/table-cells.md)

У каждого `DisplayTableTrack` есть `size` — положительный относительный вес, по умолчанию 1. Столбцы с весами 1 и 2 занимают одну и две трети ширины. Нулевые/отрицательные размеры заменяются на 1; пустой список строк/столбцов восстанавливает минимум одну полосу.

Свойства `DisplayTableCell`:

| Параметр | По умолчанию / диапазон | Назначение |
| --- | --- | --- |
| `row`, `column` | 1 / положительные целые | Положение |
| `rowSpan`, `columnSpan` | 1 / положительные целые | Объединение |
| `contentType` | `StaticText` | `StaticText`, `ChannelValue` или `ValueText` |
| `text` | Пусто | Статичный текст или текст при отсутствии подходящего правила |
| `label`, `unit` | Пусто | Подпись до / единица после значения |
| `inCnlNum` | 0 / неотрицательное | Вход ячейки |
| `previewValue` | 0 | Предпросмотр редактора |
| `displayTemplate` | `###.##` | Числовой формат предпросмотра/резервного отображения |
| `noDataText` | `#.#` | Заглушка плохих/отсутствующих данных |
| `imageName` | Пусто | Изображение из коллекции мнемосхемы |
| `rules` | Пустой список | Упорядоченный список [ValueTextRule](rules.md) |
| `useDefaultStyle` | `true` | Наследовать оформление ячеек компонента |
| `textDirection` | `Horizontal` | Собственное горизонтальное направление или поворот на 90/270 градусов |
| `textAlign` | `MiddleLeft` | Собственное выравнивание |
| `wordWrap` | `true` | Собственный перенос строк |
| `padding` | Стандартная структура отступов | Собственные отступы |
| `font` | Наследуемый | Собственный шрифт при отключении наследования |
| `foreColor`, `backColor` | Пусто | Локальные цвета |
| `trendSelectable` | `false` | Разрешить выбор канала для графика |
| `actions` | Пустой список | Упорядоченный список [DisplayCellAction](actions.md) |

Отключите `useDefaultStyle` для изменения отступов, шрифта, выравнивания, направления и переноса текста ячейки. Правила цветов/изображений могут задавать условные переопределения. Текст выводится как текст, а не исполняемый HTML.

`ChannelValue` использует форматированное хостом значение при исполнении, если оно доступно, иначе формат шаблона. `ValueText` выбирает первое подходящее правило, при отсутствии совпадений используется `text`. Непригодные числовые данные заменяются на `noDataText`. `StaticText` остаётся видимым без канала. Отрисовка сообщает о пропущенных ячейках в консоли браузера; сначала проверьте координаты и объединения, затем наличие данных.
