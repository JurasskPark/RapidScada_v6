# PlgMimDisplayJP — Настройка

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/configuration.md)

Плагин предоставляет группу электронных табло и демонстрационную группу через палитру компонентов хоста. В изученной версии исходников нет отдельного файла настроек продукта или собственного HTTP-маршрута.

Настраивайте компоненты в редакторе свойств Mimic:

- `inCnlNum` задаёт основной вход для числовых индикаторов, бегущей строки и условного текста.
- `DataTableDisplay` использует `cells[*].inCnlNum`; основной вход, выход и действие по нажатию таблицы очищаются.
- `previewValue` или `previewText` влияет только на предварительный просмотр в редакторе.
- Формат чисел, цвета и анимация относятся к выбранному типу табло.
- Ячейки таблицы имеют собственные расположение, правила и действия.

Четыре индикатора только для чтения принудительно получают `outCnlNum = 0` и пустое `clickAction`. Их унаследованные интерактивные свойства и общее оформление скрыты; используйте собственные свойства табло.

Выберите язык хоста для словарей EN/RU. Комплектный шрифт Russo One поддерживает латиницу и кириллицу. При распространении его файлов сохраняйте `OFL.txt`. См. [компоненты](components.md), [каналы](channels.md) и [ячейки таблицы](table-cells.md).
