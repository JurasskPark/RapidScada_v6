# PlgMimDisplayJP — Форматирование чисел

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/numeric-format.md)

Три числовых индикатора используют фиксированные разряды. `digitCount` принимает **1–12**; `decimalPlaces` — **0–6** для сегментного и матричного индикаторов, **0–3** для механического счётчика. Значения за границами диапазонов ограничиваются.

Числа округляются с заданной дробной точностью и выравниваются вправо. Минус занимает разряд, десятичная точка — нет. Отрицательный ноль после округления превращается в ноль. Отсутствующие/плохие данные, неконечные числа и переполнение заменяются одним прочерком на разряд без обрезки технологического значения.

Например, шесть разрядов и два дробных знака позволяют показать `1234.56` или `-123.45`, но для `12345.67` нужны семь разрядов: появятся шесть прочерков. Механический счётчик не рисует разделитель: последние дробные барабаны выделяются акцентным цветом. При семи барабанах, одном дробном знаке и ведущих нулях `1284.7` выглядит как `0012847` с выделенным последним барабаном.

Ячейки таблицы используют другой контракт. `displayTemplate` по умолчанию равен `###.##` для числового предпросмотра и резервного форматирования. Число символов `#`/`0` после точки задаёт точность, максимум 12. Только `#` убирают хвостовые дробные нули; наличие `0` сохраняет фиксированную точность. При исполнении используется `df.dispVal` хоста, если он предоставлен, поэтому шаблон не переопределяет такое форматирование хоста.

См. [параметры числовых компонентов](components.md) и [ячейки таблицы](table-cells.md).
