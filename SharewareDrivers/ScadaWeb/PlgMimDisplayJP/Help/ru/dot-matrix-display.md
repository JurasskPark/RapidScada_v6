# PlgMimDisplayJP — Матричный индикатор

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/dot-matrix-display.md)

`DotMatrixDisplay` рисует каждую цифру маской из ячеек 5 × 7 и дополнительной строкой качества. Панель, цифры, единица и подпись качества масштабируются по фактическим размерам.

| Параметр | По умолчанию / диапазон | Назначение |
| --- | --- | --- |
| `size` | 380 × 132 пикселей | Начальные размеры |
| `inCnlNum` | 0 | Основной входной канал |
| `previewValue` | -12.3 | Предпросмотр редактора |
| `digitCount` | 6 / 1–12 | Фиксированное число разрядов |
| `decimalPlaces` | 2 / 0–6 | Дробная точность |
| `unitText` | Пусто | Подпись единицы |
| `showQuality` | `true` | Показывать строку качества |
| `goodQualityText` | Пусто | Заменить локализованную подпись пригодных данных |
| `badQualityText` | Пусто | Заменить локализованную подпись плохих данных |
| `noDataQualityText` | Пусто | Заменить локализованную подпись отсутствия данных |
| `useCustomColors` | `false` | Включить пользовательские цвета |
| `displayColor` | `#55f0ad` | Активные точки |
| `panelColor` | `#07130f` | Панель |
| `showGlow` | `true` | Свечение точек |

При пустых подписях качества используется словарь плагина. В редакторе предпросмотр имеет хорошее качество. Переполнение числа показывает прочерки и плохое качество; отсутствующий вход — подпись отсутствия данных. Длинные подписи качества могут сокращаться многоточием. См. [форматирование](numeric-format.md) и [качество](channels.md).
