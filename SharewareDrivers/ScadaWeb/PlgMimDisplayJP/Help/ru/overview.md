# PlgMimDisplayJP — Обзор

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/overview.md)

PlgMimDisplayJP добавляет на стандартные мнемосхемы Mimic шесть типов электронных табло и автономный компонент `DisplayDemo`. Палитра и описания свойств доступны на русском и английском. Редактор JP не требуется.

| Компонент | Назначение | Взаимодействие |
| --- | --- | --- |
| [SegmentDisplay](segment-display.md) | Числовое табло: сегменты, светодиодный текст или ЖК-панель | Только чтение |
| [DotMatrixDisplay](dot-matrix-display.md) | Числовая матрица 5 × 7 с индикацией качества | Только чтение |
| [MechanicalCounter](mechanical-counter.md) | Числовые барабаны с выделением дробной части | Только чтение |
| [MarqueeDisplay](marquee-display.md) | Произвольный текст канала и прокрутка | Только чтение |
| [DataTableDisplay](data-table-display.md) | Объединённые ячейки, измерения, текст и изображения | Действия ячеек и выбор каналов для графика |
| [ValueTextDisplay](value-text-display.md) | Условный текст, цвета и изображения | Стандартное действие компонента по нажатию |
| [DisplayDemo](demo.md) | Локальное моделирование всех шести типов | Только элементы управления демо |

Справка описывает исходники версии **6.5.0.3** для **Rapid SCADA 6.5 / .NET 10**. Для более старой Вебстанции 6.3 нужны подходящая сборка и отдельная проверка совместимости. Метаданные продукта, проекты Web и View указывают одну версию.

Редактирование доступно без локального ключа компонента. Обычным компонентам для исполнения нужна действующая серверная лицензия. Граница описана в разделе [лицензирования](license.md); скриншоты показывают локальные примеры и не подтверждают совместимость установки.
