Adds electronic displays and flexible data panels to Rapid SCADA mimic diagrams. Show measurements, channel text and equipment states with numeric indicators, tables and conditional labels.

## Highlights

- Six components: segment and dot-matrix displays, mechanical counter, marquee, data table and conditional text.
- Three numeric panel styles with explicit overflow and data-quality indication.
- Merged table cells with formatting, images, chart selection and operator actions.
- Ordered value rules for text, colors and images.
- An autonomous demonstration with synthetic data.
