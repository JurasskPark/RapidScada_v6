# PlgMimSVGAnimationJP — Диагностика

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/troubleshooting.md)

| Симптом | Что проверить |
| --- | --- |
| Компонента нет в палитре | Регистрация плагина, согласованные сборки Web/View и включённая нативная запись |
| Дизайнер открывается, просмотрщик показывает заглушку | Состояние лицензии выполнения; свободное редактирование не включает выполнение |
| Рисунок или словарь не загружается | Путь ресурсов, оба пакета, CSS, значок, словари и кеш после обновления |
| Каталог каналов отвечает 401/403 | Авторизация, политика администратора и права просмотра/управления объектом |
| Канал нельзя выбрать | Направление/тип, активность и назначение проекта |
| Номер в JSON правильный, но данных нет | Фактические `propertyBindings`; выполнение не использует номера JSON как запасной вариант |
| Старый фейсплейт не подписан на каналы | Измените внешнее свойство экземпляра и сохраните для обновления привязок |
| Деталь замерла с обозначением отсутствия данных | Используемые входные роли, положительный статус, конечный образец и неизвестные варианты с высоким приоритетом |
| Команда недоступна | Лицензия, право управления приложения, командный канал, качество обратной связи/условия и ожидание |
| Команда доставлена, индикатор не изменился | Читайте входную обратную связь; доставка не является измеренным состоянием оборудования |
| Действие только записывается в журнал | Включён симулятор редактора |
| Импортированный SVG отличается от оригинала | Отчёт исключений, поддерживаемое подмножество и пределы сложности |
| Применение кода элемента недоступно | Новый нормализованный предпросмотр, совпадение типа, поддерживаемые поля и допустимые ресурсы |
| Группу нельзя разгруппировать | Сначала явно удалите действия группы |
| Существующая сцена открывается только для чтения | Повреждённая или неподдерживаемая схема; экспортируйте сохранённые данные перед исправлением |
| Вращение статично | Условие активности, качество данных и системный режим уменьшения движения |
| Значения HelloWorld почти не меняются | Периоды действующего синуса/треугольника измеряются минутами |
| На графике нет истории | Назначенная входная роль, `ChartFeature` приложения и содержимое архива |

Для диагностики соберите версию плагина и приложения, состояние лицензии, HTTP-статус нужного ресурса/API и минимальную сохранённую сцену. Не включайте выданную лицензию или содержимое активации в публичный отчёт об ошибке.

[Симуляция](simulation.md) отделяет проверку рисунка/правил от данных и прав приложения. Проверка документации и получение PNG не подтверждают фактическую доставку команд, обратную связь оборудования, приёмку лицензированного выполнения или целостность пакета выпуска.
