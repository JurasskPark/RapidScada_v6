# PlgMimSVGAnimationJP — Примеры 1–10: геометрия и оформление

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/examples-movement.md)

Исходные шаблоны: `Examples/HelloWorld/01–36.svganim.json`. Откройте шаблон с нужным номером в дизайнере и проверьте назначения. [Подготовка проекта и каталог каналов](examples.md).

| № | Пример | Каналы | Правило и проверка |
| --- | --- | --- | --- |
| 1 | Линия: три изменения | 101 | 101 > 0: красная, 6 px, сдвиг +100 px. Иначе: синяя линия 2 px. Переход 0,6 с. Проверка: −0,01 → 0 → +0,01. |
| 2 | Приоритет состояний | 101, 102 | 1. 101 > 0,7 → авария, красный. 2. 102 = 1 → работа, зелёный. Иначе серый. Первая строка важнее. |
| 3 | Показать / скрыть | 102 | 102 = 1 → деталь видна. 102 = 0 → деталь скрыта. Пунктирный контур остаётся ориентиром. |
| 4 | Плавная прозрачность | 101 | 101: −1 → прозрачность 15%. 101: +1 → прозрачность 100%. Между границами — линейная зависимость. |
| 5 | Горизонтальный ход | 101 | 101: −1…+1 → сдвиг X: 0…200 px. Тележка перемещается по направляющей. Вне диапазона — крайнее положение. |
| 6 | Вертикальный подъём | 103 | 103: 0…15 → сдвиг Y: 0…−94 px. Отрицательный Y поднимает деталь. Число 15 соответствует верхней точке. |
| 7 | Положение «До / После» | 102 | 102 = 1 → X +160, Y −65 px. Иначе — базовое положение. Обе координаты меняются за 0,8 с. |
| 8 | Размер по двум осям | 103 | 103: 0…15 → масштаб 50…160%. Пропорции сохраняются. Точка опоры — центр детали. |
| 9 | Растяжение по X | 101 | 101: −1…+1 → ширина 20…180%. Высота не меняется: масштаб Y = 1. Опора слева: растёт только вправо. |
| 10 | Поворот стрелки | 101 | 101: −1…+1 → угол −65…+65°. Стрелка вращается вокруг нижней точки. Центр поворота задан явно. |
