# PlgMimSVGAnimationJP — Условия, приоритеты и задержки

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/conditions.md)

Условие — плоский список проверок с `join = all` (И) или `join = any` (ИЛИ). Каждая проверка использует роль канала и оператор.

| Оператор | Соответствие |
| --- | --- |
| `=` / `!=` | Равно / не равно |
| `>` / `>=` | Больше / больше или равно |
| `<` / `<=` | Меньше / меньше или равно |
| `between` | Включительно между `value` и `upper` |
| `outside` | Вне этого интервала, без его границ |

Сравнения используют исходные конечные числа. Округлённое отображение `0` не означает, что исходное значение равно `0`. Неизвестные данные не превращаются в ноль.

## Порядок вариантов

Варианты проверяются сверху вниз. Размещайте аварийные условия перед условиями нормальной работы, если оба могут выполняться одновременно. Неизвестный вариант с более высоким приоритетом не позволяет выбрать следующий: результат неизвестен.

При `all` ложная проверка делает группу ложной, даже если другая проверка неизвестна. При `any` истинная проверка делает группу истинной вопреки другой неизвестной проверке. В остальных случаях неразрешённые проверки сохраняют неизвестный результат.

## Гистерезис

`hysteresis` действует только при выходе из уже активного порога. Для `>` / `>=` порог выхода уменьшается на полосу; для `<` / `<=` — увеличивается. Вход использует исходный порог. Равенство и интервальные операторы эту полосу не используют.

Пример: `value > 0` с `hysteresis = 0.2` включается при `0.1`, остаётся активным при `-0.1` и выключается при `-0.21`.

## Задержки

`onDelay` и `offDelay` задаются в секундах и действуют на всю группу условий. Они задерживают последующие переключения истина/ложь; первое известное состояние и первое известное состояние после восстановления данных принимаются сразу. Неизвестные данные не создают ложного условия или искусственного переключения.

Группа допускает до `100` проверок, карточка — до `100` вариантов. Стандартное условие: `join = all`, оператор `>`, `value = 50`, `upper = 100`, нулевые гистерезис и задержки; роль нужно назначить.
