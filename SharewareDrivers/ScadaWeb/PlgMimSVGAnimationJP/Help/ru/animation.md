# PlgMimSVGAnimationJP — Карточки анимации

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/animation.md)

Одна карточка управляет одним свойством одной детали. Повторное добавление свойства открывает существующую карточку. Копирование карточек на несколько выбранных деталей создаёт независимые совместимые копии и заменяет карточки того же свойства одной операцией отмены.

| Режим | Поведение |
| --- | --- |
| `condition` | Побеждает первый подходящий вариант; иначе используется базовое значение |
| `range` | Линейная интерполяция между `min` и `max`; выход за интервал ограничивается его границами |
| `cycle` | Непрерывное вращение, поток, мигание или пульсация при активном условии |
| `value` | Числовой текст с количеством знаков, префиксом и суффиксом |

## Совместимость свойств и режимов

| Свойство | Поддерживаемые режимы | Значение |
| --- | --- | --- |
| `fill` | `condition` | Цвет |
| `stroke` | `condition` | Цвет |
| `strokeWidth` | `condition`, `range` | Число |
| `opacity` | `condition`, `range`, `cycle` | Число |
| `visible` | `condition` | Логическое значение |
| `position` | `condition`, `range` | `[x, y]` |
| `scale` | `condition`, `range`, `cycle` | `[x, y]` |
| `angle` | `condition`, `range`, `cycle` | Угол |
| `level` | `condition`, `range` | Процент |
| `text` | `condition`, `value` | Текст |
| `flow` | `cycle` | Движущийся пунктир |

Группы допускают только `position`, `scale`, `angle`, `opacity` и `visible`. Контур остаётся единым объектом; анимация не редактирует его отдельные точки.

## Переходы и циклы

`duration = 0` переключает сразу. Переходы `linear` и `smooth` продолжаются к той же цели без перезапуска. При новой цели переход начинается от текущего отображаемого значения; промежуточные цели не ставятся в очередь. Положение, масштаб и угол задаются относительно базовой геометрии и используют центр преобразований детали.

Циклы используют `period` (по умолчанию `2` секунды) и `direction` (по умолчанию `1`), а также необязательное условие активности. Вращение и поток сохраняют фазу при остановке. Неактивные мигание и пульсация возвращают базовый вид. Режим уменьшения движения показывает статическое обозначение активности вместо непрерывных циклов.

Числовой текст использует `decimals` (по умолчанию `1`, допустимо `0–10`), `prefix` и `suffix`. Условия всегда вычисляются по исходному числу, а не по отформатированному тексту.

Общий планировщик анимации обрабатывает активные экземпляры. Статические символы не планируются непрерывно; обновления используют существующие узлы SVG. Удаление экземпляра или его родителя, включая фейсплейт, освобождает ресурсы анимации.
