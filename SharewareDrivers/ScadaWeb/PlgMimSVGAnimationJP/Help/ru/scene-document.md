# PlgMimSVGAnimationJP — Документ сцены и ограничения

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/scene-document.md)

`sceneDocument` хранит версионную строку JSON. Верхний уровень содержит `schemaVersion`, `canvas`, `nodes`, `resources`, `roles`, `cards` и `actions`. Детали образуют плоский массив с идентификаторами родителей.

Типы деталей: `rect`, `ellipse`, `line`, `polyline`, `polygon`, `text`, `path` и `g`. Ресурсы поддерживают локальные `linearGradient`, `radialGradient` и `clipPath`. При отрисовке идентификаторы ресурсов получают префикс экземпляра, предотвращающий столкновения символов.

| Проверяемая граница | Ограничение |
| --- | --- |
| Импорт SVG | `2097152` байта (2 МиБ) |
| JSON сцены | `8388608` символов |
| Видимые и обрезающие детали, включая развёрнутые локальные ссылки | `2000` |
| Глубина иерархии | `32` |
| Координатные токены контура / точки ломаной | `100000`; консервативный предел сложности |
| Ресурсы | `2000` |
| Точки градиента | `100` на градиент |
| Карточки анимации | `22000`; при этом одна карточка на пару деталь/свойство |
| Действия | `20000` |
| Проверки в условии / варианты в карточке | `100` / `100` |
| Размер холста | Больше `0` и не больше `100000` |
| Значение условного текста | `10000` символов |
| Сохраняемый идентификатор | `^[\w-]{1,100}$`; идентификаторы документа уникальны |

Преобразования используют конечные числа; `position` и `scale` требуют массив из двух чисел, `visible` — логическое значение, цвета и текст — строки. Недопустимые роли, повторные карточки, отсутствующие родители, циклы иерархии и неверные ресурсы отклоняются.

Повреждённая сцена или сцена неподдерживаемой версии сохраняется исходной строкой. Дизайнер предоставляет диагностику и экспорт для восстановления в режиме чтения, а не молча заменяет рисунок пустым. Перед ручным исправлением сохраните исходный документ.

Текущие образцы, выделение, таймеры, фазы анимации и ожидание команд не входят в сохраняемую сцену. [Справочник параметров](parameters.md) · [Код элемента](element-code.md)
