# PlgMimSVGAnimationJP — Симулятор редактора

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/simulation.md)

Режим проверки дизайнера использует локальные синтетические значения без локальной лицензии компонента. Он входит в редактор; отдельного автономного демонстрационного компонента нет.

Используемые роли данных группируются по назначенному входному каналу. Роли с одним положительным номером канала используют общий образец; неназначенные роли независимы. Можно менять значение и качество каждого образца.

Проверьте следующие случаи:

- Значение ниже, точно на и выше каждого порога.
- Границы интервалов, пересекающиеся варианты и неизвестные условия с высоким приоритетом.
- Вход/выход гистерезиса и удержание значений на протяжении обеих задержек.
- Концы диапазона и значения вне диапазона.
- Потеря и восстановление данных отдельной детали при продолжении работы независимых деталей.
- Доступность команд/меню и отдельные роли обратной связи.

Нажатие действия записывает его в журнал симулятора без отправки команд SCADA, открытия графиков приложения или переходов. Успех симуляции не подтверждает лицензию выполнения или действующие права приложения.

Изменения режима проверки не сохраняются как реальные входные значения. Остановите проверку для редактирования базовой геометрии, затем примените дизайнер и сохраните документ.

Локальный сервер примеров в исходниках запускается из `Plugins/Mimics/PlgMimSVGAnimationJP`:

~~~powershell
node Scripts/ServeExamples.mjs
~~~

Он показывает примеры на порту `11140` через тот же механизм рисунка с синтетическими образцами. Это средство разработки, а не установленный просмотр SCADA.
