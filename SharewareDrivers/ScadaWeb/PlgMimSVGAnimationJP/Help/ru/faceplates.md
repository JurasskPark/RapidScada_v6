# PlgMimSVGAnimationJP — Фейсплейты и фактические каналы

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/faceplates.md)

`SvgAnimation` поддерживает обычные мнемосхемы и вложенные фейсплейты. Адаптер создаёт внешние стандартные привязки `svgFaceplate_<component ID path>_<encoded role>`; имя свойства не содержит точек.

Приложение разрешает эти привязки через обычные механизмы поставщика и вычисляемых каналов. Назначения экземпляра, существующие пользовательские привязки и дополнительные скрипты сохраняются. Выполнение использует разрешённую привязку, а не сохранённый исходный номер сцены.

Для старого `.mim` с существующим экземпляром фейсплейта измените внешнее свойство экземпляра и сохраните документ, чтобы сформировать внешние привязки и подписки сервера. Одно открытие документа эту миграцию не выполняет. Новая вставка экземпляра получает привязки автоматически.

Пример: канал роли `1` плюс `cnlOffset = 110` экземпляра даёт канал `111`. Проверяйте и обратную связь, и командные роли конкретного экземпляра; не отправляйте пробную команду только по номеру из шаблона.

Удаление вложенного фейсплейта также освобождает его экземпляры анимации SVG. [Роли каналов](channels.md) · [Миграция](migration.md)
