# PlgMimSVGAnimationJP — Переименование и перенос документов

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/migration.md)

Прежнее имя продукта — `PlgSVGAnimationJP`. Текущие сборки, метаданные и имя продукта лицензии — `PlgMimSVGAnimationJP`. Сохраняются сериализованный тип компонента `SvgAnimation`, браузерный API `SvgAnimationJP`, адрес `/api/plugins/svg-animation-jp/channels` и схема сцены `1`.

1. Сохраните резервную копию документов мнемосхем/фейсплейтов и установленного плагина.
2. Отключите старую регистрацию плагина.
3. Установите и зарегистрируйте полный текущий пакет Web/View/ресурсов для согласованного приложения.
4. Проверьте открытие существующих сцен без ошибок валидации.
5. Обновите внешние привязки старых экземпляров фейсплейтов согласно [инструкции](faceplates.md).
6. Сохраните документы и проверьте фактические роли каналов перед проверкой выполнения.
7. Сформируйте запрос активации текущего продукта, если старый ключ выдан для прежнего имени приложения.

Не загружайте обе регистрации плагина. Переименование старой подписанной лицензии не создаёт ключ текущего продукта.

Старый архив `1.0.3` является историческим материалом, а не текущим пакетом `6.5.0.3`. Повреждённые сцены и сцены будущих версий сохраняют исходные данные для восстановления; они не превращаются молча в пустые сцены.
