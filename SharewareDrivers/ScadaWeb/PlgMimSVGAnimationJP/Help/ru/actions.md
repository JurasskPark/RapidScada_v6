# PlgMimSVGAnimationJP — Действия оператора

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/actions.md)

Назначайте действия детали или группе. Одно действие открывается сразу; несколько действий показывают меню, а не последовательность автоматических операций. Приоритет имеет самая глубокая нажатая деталь с действиями; иначе используется ближайшая родительская группа. Enter и пробел активируют детали, доступные с клавиатуры.

| Тип | Поведение |
| --- | --- |
| `command` | Открывает стандартный диалог значения команды приложения для командной роли |
| `fixedCommand` | Отправляет фиксированное числовое значение после подтверждения |
| `chart` | Открывает график приложения для входной роли через `ChartFeature` |
| `view` | Открывает положительный `viewID` |
| `link` | Открывает абсолютный HTTP/HTTPS `url` в новой вкладке |

Внешние ссылки используют `noopener` и `noreferrer`. Относительные адреса и другие схемы не принимаются.

## Доступность и подтверждение

Выполнение должно быть разрешено, а качество данных — допускать действие. Необязательное `condition` должно быть истинным. Если настроено `feedback`, образец его входного канала должен быть пригоден. Для команд дополнительно нужны `controlRight` приложения, фактический положительный выходной канал и отсутствие ожидающей команды этого канала.

Ожидание отслеживается для каждого канала в течение `30` секунд. Автоматической повторной отправки нет. Ответ о доставке не устанавливает значение обратной связи: перерисовка использует подтверждённое состояние входного канала. Для командной уставки и измеренной обратной связи используйте разные роли.

В симуляторе редактора действия только записываются в журнал. Они не вызывают API команд, графиков или переходов.

## Сохраняемые поля и значения по умолчанию

| Поле | Значение / назначение |
| --- | --- |
| `id`, `node` | Идентификатор действия и целевая деталь |
| `type` | `command` |
| `label` | Видимая пользователю подпись |
| `role` | Пусто; назначьте входную или командную роль согласно типу |
| `feedback` | Пусто; необязательная входная роль обратной связи |
| `value` | `1` |
| `viewID` | `1` |
| `url` | `https://`; замените полным адресом |
| `condition` | `null`; дополнительного условия доступности нет |
