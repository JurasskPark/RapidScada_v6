# PlgMimSVGAnimationJP — Роли и привязки каналов

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/channels.md)

Роль отделяет смысл символа от номера канала проекта. Каждая роль содержит `id`, `name`, `direction` и `cnlNum`. Направление `data` читает входные значения; `command` адресует выходной канал. `cnlNum = 0` означает отсутствие назначения. Положительные номера каналов — целые безопасные числа не больше `2147483647`.

Назначайте каналы вручную или через [каталог](channel-catalog.md). Входная обратная связь и выходная команда требуют отдельных ролей, даже если номера каналов совпадают.

Применение сцены создаёт стандартные `propertyBindings` с именами `svgRole_<id>` и `dataSource = channel` для назначенных ролей данных и команд. Существующие пользовательские привязки сохраняются. Изменения сцены и привязок передаются приложению совместно.

При выполнении номера каналов берутся исключительно из разрешённых `component.bindings.propertyBindings`. Исходный `cnlNum` из JSON не служит запасным вариантом. Поэтому отсутствующую или устаревшую привязку приложения нельзя исправить простым указанием номера в строке сцены.

Для экземпляра фейсплейта приложение разрешает фактические каналы. Например, сохранённый канал `1` с `cnlOffset = 110` становится `111` для ролей данных или команд. Перед проверкой выполнения сверяйте назначение конкретного экземпляра.

Рисунок читает роли данных; командные роли сами по себе не требуют входных образцов. Обратная связь и условия действий могут добавлять собственные требования к данным.
