# PlgMimSVGAnimationJP — Лицензия и правила выполнения

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/license.md)

Создание рисунков бесплатно; для выполнения в Вебстанции нужна лицензия.

| Контекст | Поведение |
| --- | --- |
| Редактор мнемосхем/фейсплейтов | Полная палитра и дизайнер, импорт/экспорт, настройка анимации и действий, применение и симулятор без локального ключа компонента |
| Вебстанция с действующей подписанной лицензией сервера | Рисунок, анимация по каналам и действия оператора с учётом прав приложения |
| Лицензия отсутствует/недействительна либо проверка завершилась ошибкой | Локализованная неактивная заглушка; без привязок компонента, анимации, обращений к данным/API или команд |

Состояние лицензии этого компонента не отключает другие плагины и общий опрос просмотрщика. Устанавливайте полный пакет плагина. Просмотрщик Вебстанции не позволяет открыть дизайнер.

Состояния включают `valid`, `missing`, `invalid` и `error`. Установленный ключ выполнения проверяется на сервере; видимый водяной знак — отдельный механизм, который не подтверждает активацию.

Эти правила лицензирования относятся к версии `6.5.0.3`. При обновлении старых версий см. [миграцию](migration.md).

Коммерческое использование определяется условиями выданной лицензии. Цена, новое видео и подтверждённый контакт поддержки в проверенных материалах не найдены. [Активация](activation.md) · [Границы материалов](sources.md)
