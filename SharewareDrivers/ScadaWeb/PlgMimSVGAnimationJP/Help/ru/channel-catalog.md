# PlgMimSVGAnimationJP — Каталог каналов и интеграция

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/channel-catalog.md)

Таблица каналов дизайнера ищет по номеру, имени, коду и тегу, с фильтрами объекта и устройства. Фильтрация выполняется до разбивки на страницы. Неактивные каналы видны, но выбрать их нельзя. При доступном каталоге вручную введённые номера проверяются.

## Приложения и права

| Приложение | Адрес / поставщик |
| --- | --- |
| Вебстанция | `GET /api/plugins/svg-animation-jp/channels`; политика администратора и права просмотра/управления объектом |
| WebAdmin | `GET /api/admin/mimic-editor/channels`; рабочая область текущего проекта |
| Собственное приложение редактора | `channelCatalogProvider.query(request, abortSignal)` |

Вебстанция использует свою `ConfigDatabase`. Выбор входных каналов допускает типы `1–4` с правами просмотра; выбор команд — типы `2, 4, 5` с правами управления. Это права каталога; они не предоставляют права управления при выполнении.

| Параметр | Значение / ограничение |
| --- | --- |
| `term` | Строка поиска; не больше `200` символов |
| `direction` | `data` или `command` |
| `objNum`, `deviceNum` | Необязательные фильтры |
| `page` | По умолчанию `1`; ограничивается `1–1000000` |
| `pageSize` | По умолчанию `50`; ограничивается `1–100` |
| `cnlNums` | Номера каналов через запятую для адресного поиска; не больше `2200` символов |

Ответ содержит `items`, `totalItems`, `page`, `pageSize`, `objects` и `devices`. Элемент описывает номер канала, имя, код, тег, активность, тип, объект и устройство.

## Адаптер поставщика

Зарегистрируйте своего поставщика через `SvgAnimationJP.registerChannelCatalog(provider)` либо создайте HTTP-адаптер через `SvgAnimationJP.httpCatalog(endpoint)`. Передавайте каталог согласно контракту приложения; браузеру не требуется конкретная реализация базы данных.

Новый запрос отменяет предыдущий; проверка версии запроса отбрасывает устаревшие ответы. Закрытие диалога отменяет ожидающую работу. При отсутствии поставщика ручное назначение каналов остаётся доступным.
