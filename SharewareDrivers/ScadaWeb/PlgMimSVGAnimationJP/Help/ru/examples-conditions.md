# PlgMimSVGAnimationJP — Примеры 21–30: логика и качество

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/examples-conditions.md)

Исходные шаблоны: `Examples/HelloWorld/01–36.svganim.json`. Откройте шаблон с нужным номером в дизайнере и проверьте назначения. [Подготовка проекта и каталог каналов](examples.md).

| № | Пример | Каналы | Правило и проверка |
| --- | --- | --- | --- |
| 21 | Два условия: И | 101, 102 | 101 > 0 И 102 = 1 → зелёный. Оба условия должны выполняться. Проверка: (0,5; 1), (−0,5; 1), (0,5; 0). |
| 22 | Два условия: ИЛИ | 101, 103 | 101 > 0,6 ИЛИ 103 > 12 → красный. Достаточно любого из двух условий. Остальные состояния — серый. |
| 23 | В диапазоне / вне | 101 | Зелёный: −0,3 ≤ 101 ≤ +0,3. Оранжевый: 101 вне этого диапазона. Границы −0,3 и +0,3 включены. |
| 24 | Все числовые сравнения | 101 | Шесть индикаторов сравнивают 101 с нулём. Проверка: −0,1 → 0 → +0,1. Равенство относится к точному числу. |
| 25 | Гистерезис порога | 101 | Вход: 101 > 0. Выход: 101 ≤ −0,2. Слева обычный порог, справа гистерезис. Проверка: 0,1 → −0,1 → −0,21. |
| 26 | Задержки включения | 102 | 102 = 1: включение через 2 с. 102 = 0: выключение через 1 с. Слева сразу, справа с задержкой. |
| 27 | Мгновенно и плавно | 102 | 102 = 1 → сдвиг +170 px; 0 → назад. Сверху сразу, снизу плавно за 2 с. Новая цель заменяет текущую без очереди. |
| 28 | Группа и вложенные детали | 103, 101, 102 | 103: 0…15 → группа едет на 100 px. Внутри: вращение при 101 ≥ −1. 102 = 1 независимо меняет цвет лопасти. |
| 29 | Нет данных: изоляция | 300, 101 | 300 отключён в базе: слева «Нет данных». Справа 101 продолжает менять цвет. В «Проверить» меняйте качество отдельно. |
| 30 | Два устройства | 101, 107 | 101 — синус устройства 1. 107 — синус устройства 2. Одинаковая геометрия, отдельные привязки. |
