## Компонент и холст

| Свойство | Значение / назначение |
| --- | --- |
| Размер компонента | `160 × 120` |
| `inCnlNum`, `outCnlNum` | `0`; каналы назначаются через роли |
| `clickAction` | Пусто |
| Толщина рамки / фон | `0` / прозрачный |
| `sceneDocument` | Сериализованная пустая сцена |
| `schemaVersion` | `1` |
| `canvas.width`, `canvas.height` | `320`, `240` |
| `canvas.background` | `none` |

Унаследованные редакторы каналов, действий и состояний компонента скрыты; используйте специальный редактор рисунка и анимации. Размер компонента и внутреннего холста задаются отдельно.

## Поля детали

| Поле | Значение / назначение |
| --- | --- |
| `id`, `type`, `name`, `parent` | Постоянный идентификатор, тип фигуры, локализованное исходное имя, родительская группа либо `null` |
| `x`, `y` | `0`, `0` |
| `width`, `height` | `80`, `60` |
| `boundsX`, `boundsY` | `0`, `0` |
| `angle`, `scaleX`, `scaleY` | `0`, `1`, `1` |
| `pivotX`, `pivotY` | `40`, `30` |
| `matrix` | `[1, 0, 0, 1, 0, 0]` |
| `fill` | `#e2e8f0`; `none` для линии/ломаной |
| `stroke`, `strokeWidth` | `#334155`, `2` |
| `opacity`, `visible` | `1`, `true` |
| `fillOpacity`, `strokeOpacity`, `fillRule` | `1`, `1`, `nonzero` |
| `rx` | `0`; радиус углов прямоугольника |
| `points` | `[[0, 0], [80, 60]]` |
| `text` | Локализованный исходный текст |
| `fontSize`, `fontFamily`, `bold`, `textAlign` | `20`, `sans-serif`, `false`, `start` |
| `dash`, `linecap`, `linejoin` | Пусто, `round`, `round` |
| `arrowStart`, `arrowEnd` | `false`, `false` |
| `level`, `levelDirection`, `levelColor` | `100`, `bottom`, `#38bdf8` |
| `path`, `clip` | Пусто |
| `locked`, `editorHidden` | `false`, `false`; состояние только редактора |

Направления уровня: `bottom`, `top`, `left` и `right`. Локальные ресурсы должны разрешаться внутри сцены. Цвета, геометрия и иерархия проверяются перед выполнением.

## Значения карточек по умолчанию

| Поле | Значение |
| --- | --- |
| `id`, `node`, `property` | Идентификатор карточки, цель и свойство |
| `mode` | Первый поддерживаемый режим выбранного свойства |
| `duration`, `easing` | `0`, `linear` |
| `role` | Пусто |
| `min`, `max` | `0`, `100` |
| `from`, `to` | Базовое значение свойства |
| `variants` | Один вариант со стандартным условием и базовым значением |
| `condition` | Стандартное условие |
| `period`, `direction` | `2` секунды, `1` |
| `decimals`, `prefix`, `suffix` | `1`, пусто, пусто |

Базовые значения анимации для `position`, `scale` и `angle` / `flow` — `[0, 0]`, `[1, 1]` и `0`. Остальные свойства берутся из сохранённого значения детали.
