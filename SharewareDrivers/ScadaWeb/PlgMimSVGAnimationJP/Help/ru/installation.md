# PlgMimSVGAnimationJP — Установка и обновление

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/installation.md)

## Совпадение версий

Проверенные манифест, Web- и View-сборки имеют версию `6.5.0.3` и предназначены для .NET 10 / Rapid SCADA 6.5. Используйте согласованные сборки приложения и плагина. Совместимость этой версии с Вебстанцией 6.3 не подтверждена.

Нужен полный пакет, собранный из соответствующей версии исходников. В этом каталоге документации находятся Markdown и PNG, а не установочный ZIP.

## Размещение пакета

| Каталог | Необходимое содержимое |
| --- | --- |
| `ScadaWeb` | `PlgMimSVGAnimationJP.dll` и согласованная зависимость приложения `PlgMimic.Common` |
| `ScadaWeb/lang` | Файлы фраз плагина |
| `ScadaWeb/wwwroot/plugins/MimSVGAnimationJP` | CSS, `js/svg-animation.bundle.js`, `js/zz-runtime-license.js`, значки и `locales/en-GB.json` / `locales/ru-RU.json` |
| `ScadaAdmin/Lib` | View-сборка плагина и согласованные зависимости из пакета |

Переносимый пакет размещает View DLL в `ScadaAdmin/Lib`. Нативная установка приложения может использовать свой каталог плагинов; соблюдайте структуру конкретного пакета. Переносимый импорт использует согласованные общие зависимости приложения. Используйте поддерживаемый приложением механизм регистрации или импорта плагинов. Идентификатор нативного манифеста — `plg-mim-svg-animation-jp`, возможность компонента — `mimic.component.svg-animation`. Не подменяйте `ScadaCommon` и `ScadaWebCommon` произвольными копиями.

## Проверка установки

1. Зарегистрируйте плагин, перезапустите соответствующее приложение и откройте редактор заново.
2. Убедитесь, что `SvgAnimation` появился в палитре и дизайнер открывается.
3. Проверьте загрузку обоих JavaScript-пакетов и нужного словаря без ошибок HTTP.
4. Примените тестовый символ и сохраните его.
5. Перед проверкой выполнения проверьте лицензию и доступ к назначенным каналам.

Перед обновлением пакетов закройте сеансы редактора. Сохраните резервную копию документов проекта и предыдущего пакета. Старая регистрация `PlgSVGAnimationJP` не должна работать одновременно с переименованным плагином: см. [миграцию](migration.md).
