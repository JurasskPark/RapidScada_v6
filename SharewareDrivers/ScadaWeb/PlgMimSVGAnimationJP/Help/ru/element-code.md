# PlgMimSVGAnimationJP — Редактирование кода элемента

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/element-code.md)

Кнопка `</>` открывает код одной выбранной детали. Это ограниченный редактор модели сцены, а не средство выполнения произвольного DOM/SVG-скрипта.

- Режим SVG принимает одну деталь того же типа, меняет локальную геометрию, оформление и поддерживаемые локальные ресурсы. Он сохраняет размещение, угол, центр преобразований, стрелки и назначенные действия.
- Режим JSON редактирует полные параметры детали. Он не позволяет менять `id`, `parent` или `type`.
- Группы используют только JSON. Контур редактируется целиком; интерактивного редактора узлов контура нет.

Перед применением выполните проверку и предпросмотр. `Ctrl+Enter` запускает предпросмотр. Он показывает нормализованный результат. Изменение кода отменяет прежний предпросмотр; недопустимые, неизвестные или неподдерживаемые поля блокируют применение.

«Применить» переносит результат в черновик дизайнера одной операцией отмены. Отмена или Esc ничего не меняют. Для сохранения примените внешний дизайнер и сохраните документ.

Проверка не исполняет переданную разметку как исходный DOM. Ограничения SVG и сложности продолжают действовать. [Импорт SVG](import-export.md) · [Ограничения сцены](scene-document.md)
