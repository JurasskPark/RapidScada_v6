# PlgMimSVGAnimationJP — Примеры 31–36: действия и повторное использование

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/examples-interaction.md)

Исходные шаблоны: `Examples/HelloWorld/01–36.svganim.json`. Откройте шаблон с нужным номером в дизайнере и проверьте назначения. [Подготовка проекта и каталог каналов](examples.md).

| № | Пример | Каналы | Правило и проверка |
| --- | --- | --- | --- |
| 31 | Реле: команды 0 / 1 | 110, 110 (команда) | Меню ВКЛ / ВЫКЛ → канал 110. При первом запуске: «Первое значение» → 0. Индикатор меняется по обратной связи 110. |
| 32 | Аналоговый выход | 111, 111 (команда) | Меню: значения 0 / 5 / 10 → канал 111. При первом запуске: «Первое значение» → 0. Шкала 0…10 показывает обратную связь 111. |
| 33 | График по нажатию | 101, 103 | Каждая кнопка открывает график канала. Используется штатный механизм SCADA. В симуляторе нажатие попадёт в журнал. |
| 34 | Переходы и ссылки |  | Представление 2 — таблица Simulator. Вторая кнопка — HTTP-ссылка на список схем. Переходы выполняются только по нажатию. |
| 35 | Контур path и градиент | 101 | Path редактируется через кнопку &lt;/&gt;. 101: −1…+1 → масштаб 70…130%. Градиент не требует внешних файлов. |
| 36 | Шаблон: другие каналы | 201, 200, 202 | 200 — синус, 201 — дискрет, 202 — уровень. Те же фигуры, другой набор назначений. Меняйте номера в одной таблице каналов. |
