# PlgMimSVGAnimationJP — Примеры 11–20: циклы и оборудование

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/examples-equipment.md)

Исходные шаблоны: `Examples/HelloWorld/01–36.svganim.json`. Откройте шаблон с нужным номером в дизайнере и проверьте назначения. [Подготовка проекта и каталог каналов](examples.md).

| № | Пример | Каналы | Правило и проверка |
| --- | --- | --- | --- |
| 11 | Непрерывное вращение | 103 | 103 ≥ 0 → ротор вращается, период 3 с. Корпус неподвижен. Вращается группа. При отсутствии данных вращение замрёт. |
| 12 | Пульсация размера | 103 | 103 ≥ 0 → пульсация с периодом 1,4 с. Масштаб колеблется около базового. Опора в центре, без сдвига детали. |
| 13 | Ёмкость с уровнем | 103 | 103: 0…15 → заполнение 0…100%. Жидкость растёт снизу вверх. Контур ёмкости остаётся неподвижным. |
| 14 | Четыре направления уровня | 103 | Один канал 103, диапазон 0…15. Снизу, сверху, слева и справа. Каждая шкала — отдельная деталь. |
| 15 | Бегущий пунктир | 103 | 103 ≥ 0 → два потока навстречу. Период 0,6 с; направления +1 и −1. Контур трубы и стрелки неподвижны. |
| 16 | Мигание по сигналу | 102 | 102 = 1 → мигание с периодом 0,8 с. 102 = 0 → базовый вид без мигания. Мигает прозрачность, а не вся схема. |
| 17 | Насос: независимые правила | 101, 102 | 102 = 1 → вращение ротора, период 2 с. 101 > 0,6 → красный корпус. Остановка сохраняет текущую фазу. |
| 18 | Клапан по обратной связи | 110 | 110 = 1 → клапан открыт. 110 = 0 → клапан закрыт. Канал 110 меняется командой (пример 31). |
| 19 | Регулирующая заслонка | 103 | 103: 0…15 → поворот 0…90°. Плавное регулирование по треугольнику. Корпус и подписи не вращаются. |
| 20 | Значение и формат текста | 101, 103, 111 | 101: 3 знака; 103: 2; 111: 1 знак. Отображается число, а не выражение. Для условий используется исходная точность. |
