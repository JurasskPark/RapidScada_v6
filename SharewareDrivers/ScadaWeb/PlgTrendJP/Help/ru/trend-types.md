# PlgTrendJP — Типы тренда

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/trend-types.md)

Откройте **Действия → Тип тренда** и выберите представление, подходящее данным.

| Значение | Рекомендуемое применение |
| --- | --- |
| `line` | Обычные аналоговые значения. |
| `points` | Отдельные отсчёты без соединяющих линий. |
| `line-markers` | Линия с видимыми положениями отсчётов. |
| `stepped` | Дискретные, удерживаемые значения и состояния. |
| `smooth` | Визуально сглаженная технологическая кривая. |
| `area` | Область с заливкой под кривой. |
| `bar` | Сравнение значений столбиками. |
| `multiple-axes` | Каналы с разными числовыми диапазонами, объединённые максимум в четыре оси Y. |
| `limits` | Тренды каналов с настроенными нижними и верхними границами. |
| `polar` | Последние значения как углы на диаграмме 360°. |
| `pie` | Последние достоверные значения в виде секторов. |
| `radial-gauge` | Последние значения максимум шести первых рядов в виде радиальных индикаторов. |
| `single-gauge` | Последнее значение первого доступного ряда. |
| `normalized-gauge` | Последние значения максимум шести первых рядов, нормализованные до `0–100%`. |
| `dynamogram` | Первые два канала, объединённые по одинаковому времени достоверных точек. |

Режимы `pie`, индикаторы и полярная диаграмма используют последние достоверные значения, а не всю временную кривую. Для `dynamogram` требуется не менее двух каналов.
