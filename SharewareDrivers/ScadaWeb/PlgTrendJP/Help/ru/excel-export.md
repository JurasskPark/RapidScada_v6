# PlgTrendJP — Экспорт Excel

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/excel-export.md)

1. Сначала загрузите требуемый тренд.
2. Откройте **Действия → Экспорт Excel**.
3. Выберите **Широкий** или **Длинный** формат.
4. Включите **Разделять по суткам**, если нужны отдельные суточные листы.
5. Запустите экспорт и не закрывайте страницу до готовности файла.

| Настройка | Результат |
| --- | --- |
| **Широкий** | Один общий столбец времени и столбцы значения и качества для каждого канала. |
| **Длинный** | Последовательные строки даты и времени, тега, значения и качества. |
| **Разделять по суткам** | Отдельный лист `yyyy-MM-dd` для каждых локальных суток. |
| **Сводка** | Архив, канал, тег, количество точек, минимум, максимум и среднее достоверных значений. |

Первая строка каждого листа закрепляется. Microsoft Excel не требуется на сервере SCADA Web. Один экспорт ограничен 10 000 000 точек и лицензированным количеством уникальных каналов.
