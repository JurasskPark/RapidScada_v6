# PlgTrendJP — TrendWindow на мнемосхеме

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/trendwindow-on-a-mimic-diagram.md)

`TrendWindow` — компактный интерактивный тренд, размещаемый непосредственно на мнемосхеме. В редакторе показываются демонстрационные данные, поэтому внешний вид можно настроить без доступа к архиву. Во время выполнения компонент загружает реальные данные и поддерживает подсказки, масштабирование колесом, перемещение, сброс масштаба и интерактивную легенду.

У компонента намеренно нет заголовка и постоянной кнопки перехода. Если `openOnClick=true`, обычный щелчок открывает полную страницу TrendJP в новой вкладке. Масштабирование, перемещение, сброс масштаба и щелчки по легенде страницу не открывают. В режиме редактирования щелчок только выделяет компонент.

## Свойства TrendWindow

| Свойство | По умолчанию | Назначение |
| --- | --- | --- |
| **Каналы** (`channelNumbers`) | `1` | Список или диапазоны каналов. |
| **Архив** (`archiveCode`) | `Min` | Архив компонента. |
| **Период** (`periodValue`) | `1` | Положительное значение скользящего периода. |
| **Единица периода** (`periodUnit`) | `h` | Секунды (`s`), минуты (`m`) или часы (`h`). |
| **Шаблон** (`preset`) | `default` | Светлая `default` или тёмная тема. |
| **Прозрачный фон** (`transparentBackground`) | `true` | Показывает подложку мнемосхемы сквозь фон графика. |
| **Тип тренда** (`trendType`) | `line` | Один из поддерживаемых типов тренда. |
| **Показывать легенду** (`showLegend`) | `true` | Включает или отключает легенду. |
| **Положение легенды** (`legendPosition`) | `top` | `none`, `top`, `right`, `bottom` или `left`. |
| **Маркер точки** (`markerShape`) | `circle` | `circle`, `triangle` или `square`; также используется в подсказке. |
| **Толщина линии** (`lineWidth`) | `2` | Толщина линии в CSS-пикселях. |
| **Размер точки** (`markerSize`) | `3` | Размер точки в CSS-пикселях. |
| **Автообновление** (`autoRefresh`) | `true` | Включает периодические запросы во время выполнения. |
| **Обновление, сек** (`refreshSeconds`) | `30` | Задержка обновления; `0` останавливает периодическое обновление. |
| **Открывать страницу тренда по клику** (`openOnClick`) | `true` | Открывает полную страницу с соответствующими настройками. |

Старое свойство `periodHours` по-прежнему принимается при открытии существующей мнемосхемы. Новые компоненты используют `periodValue` и `periodUnit`.
