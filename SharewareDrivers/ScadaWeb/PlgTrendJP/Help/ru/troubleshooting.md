# PlgTrendJP — Устранение неполадок

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/troubleshooting.md)

| Признак | Причина и действие |
| --- | --- |
| TrendJP отсутствует в Вебстанции | Проверьте регистрацию, установленные файлы и перезапустите SCADA Web. |
| Стандартная команда открывает другой плагин | Назначьте `<ChartFeature>PlgTrendJP</ChartFeature>`. |
| Ошибка лицензии | Проверьте имя, папку лицензии, `AppName=PlgTrendJP`, положительный `CountTags` и перезапустите приложение. |
| Превышен лимит каналов | Сократите количество уникальных номеров или используйте подходящую лицензию. |
| Список архивов пуст | Проверьте настройку архивов проекта. |
| Выбранный канал не содержит данных | Проверьте принадлежность канала архиву и качество данных. |
| На линии есть разрывы | Отсутствующие, ошибочные и недостоверные точки намеренно не соединяются. |
| Одна линия Multiple axes выглядит прямой | Проверьте ручные группы осей. Сильно различающиеся диапазоны в одной группе используют общую шкалу. |
| Назад/Вперёд использует неожиданный интервал | Откройте **Настройки отображения** и проверьте шаг, единицу и режим сдвига/расширения. |
| Скрытый ряд не возвращается | Щёлкните приглушённый элемент легенды или повторно изолируйте единственный видимый ряд. |
| Профиль отсутствует на другом рабочем месте | Профили локальны для браузера. Общие значения задавайте в `View.Args`. |
| Не работает выражение с `+` | Кодируйте плюс как `%2B`, например `DAY%2B1D`. |
| Автообновление не запускается | Нажмите **Старт** или задайте `autoRefresh=true`; `refreshInterval` только выбирает период. |
| Элементы управления не видны | `showToolbar=false` скрывает и **Действия**. Используйте `showControlPanel=false`, чтобы сохранить меню. |
| Экспорт Excel отклонён | Сначала загрузите тренд, не закрывайте страницу и проверьте лимиты точек и каналов. |
