# PlgTrendJP — Элементы основной страницы

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/main-page-controls.md)

| Элемент | Назначение |
| --- | --- |
| **Каналы** | Открывает выбор каналов. Количество уникальных номеров ограничивается лицензией `CountTags`. |
| **Архив** | Выбирает текущий, минутный, часовой, суточный или другой настроенный архив. |
| **Несколько архивов** | Включает до четырёх независимо настраиваемых архивных источников. |
| **От**, **До** | Задаёт загружаемый диапазон локального времени с точностью до секунды. |
| **Таймер** | Выбирает `Auto` или фиксированный интервал. Кнопки **Старт** и **Стоп** управляют периодическим обновлением. |
| **Подсказка** | Переключает подсказку ближайшего канала и всех каналов во времени курсора. |
| **Обновить** | Загружает данные для дат, указанных в полях календаря. |
| **Сбросить масштаб** | Возвращает полный загруженный диапазон времени. |
| **Действия** | Открывает выбор типа графика, настройки отображения, профили и экспорт Excel. |
| **Временная шкала** | Показывает полный загруженный период и текущее видимое окно. |
