# PlgTrendJP — Настройка отдельного представления

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/configuring-a-standalone-view.md)

Плагин регистрирует тип представления без отдельного файла — `TrendJP`. Настроенное представление открывает `/TrendJP?viewID=<ID>`. Поле `Args` содержит обычные параметры строки запроса без начального `?`.

## Аргументы данных и времени

| Параметр | Значения; по умолчанию | Назначение |
| --- | --- | --- |
| `cnlNums` | Выражение каналов; пусто | Входные каналы. |
| `archiveCode` | Код архива; `Min` | Архив одиночного режима. Алиас: `archive`. |
| `startTime` | Абсолютное или относительное локальное время | Начало диапазона. Алиас: `from`. |
| `endTime` | Абсолютное или относительное локальное время | Конец диапазона. Алиас: `to`. |
| `period` | Положительное число и `s`, `m` или `h` | Формирует диапазон при отсутствии границы. |
| `hours` | Положительное число часов | Устаревший совместимый период в часах. |

Без `startTime`, `endTime`, `period` и `hours` TrendJP открывает полные текущие локальные сутки от `00:00` до следующих `00:00`.

## Аргументы отображения и поведения

| Параметр | Значения; по умолчанию | Назначение |
| --- | --- | --- |
| `theme` | `default`, `dark`; `default` | Тема страницы. |
| `trendType` | См. типы тренда; `line` | Представление графика. |
| `showLegend` | Логическое значение; `true` | Совместимый флаг легенды; `false` имеет приоритет. |
| `legendPosition` | `none`, `top`, `right`, `bottom`, `left`; `top` | Положение легенды. |
| `markerShape` | `circle`, `triangle`, `square`; `circle` | Маркер графика и подсказки. |
| `lineWidth` | `1`, `1.5`, `2`, `3`, `4`; `2` | Толщина линии. |
| `markerSize` | `2`, `3`, `4`, `5`, `6`, `8`; `3` | Размер точки. |
| `tooltip` | `nearest`, `all`; `nearest` | Режим подсказки. |
| `refreshInterval` | `auto`, `1`, `5`, `10`, `30`, `60`; `30` | Период таймера; сам его не запускает. |
| `autoRefresh` | Логическое значение; `false` | Запускает периодическое обновление после открытия. |
| `showToolbar` | Логическое значение; `true` | `false` скрывает всю панель, включая **Действия**. |
| `showControlPanel` | Логическое значение; `true` | Скрывает фильтры, сохраняя **Действия**. |
| `showTimeline` | Логическое значение; `true` | Показывает временную шкалу и кнопки Назад/Вперёд. |
| `navigationStep` | Положительное целое; `1` | Шаг Назад/Вперёд. |
| `navigationUnit` | `s`, `m`, `h`, `d`; `d` | Секунды, минуты, часы или дни. |
| `navigationMode` | `shift`, `expand`; `shift` | Сдвигает обе границы или расширяет одну границу. |
| `axisGroup1` ... `axisGroup4` | Выражения каналов; пусто | Ручное назначение Multiple axes. Другие типы не используют. |
| `exportLayout` | `wide`, `long`; `wide` | Формат Excel по умолчанию. |
| `splitByDay` | Логическое значение; `false` | Создаёт отдельные суточные листы. |

Для логических аргументов используйте `true` и `false`. Общий обработчик также принимает `1` как истину, а `0`, `no` и `off` — как ложь.

## Аргументы нескольких архивов

| Параметр | Значения | Назначение |
| --- | --- | --- |
| `multiArchive` | Логическое значение; `false` | Включает несколько источников. Алиас: `multi`. |
| `sourceNArchive` | Код архива, `N=1..4` | Архив источника `N`. Алиас: `archiveN`. |
| `sourceNCnlNums` | Выражение каналов, `N=1..4` | Каналы источника `N`. Алиас: `cnlNumsN`. |
| `sourceNEnabled` | Логическое значение, `N=1..4`; включено | Включает или отключает источник `N`. Алиас: `enabledN`. |

Аргументы источников автоматически включают режим нескольких архивов. Один встроенный `TrendWindow` использует только один архив и один список каналов.

## Синтаксис каналов

Выражения каналов принимают запятые, точки с запятой и пробелы как разделители. Возрастающие и убывающие диапазоны раскрываются, ошибочные и неположительные номера игнорируются, а дубликаты удаляются с сохранением первого вхождения.

| Выражение | Результат |
| --- | --- |
| `100, 200-203, 310` | `100,200,201,202,203,310` |
| `10; 12 14-16` | `10,12,14,15,16` |
| `5-2, 3, 5` | `5,4,3,2` |

Фактический максимум задаётся положительным значением `CountTags` в лицензии. Один номер канала, повторённый в нескольких архивных источниках, учитывается один раз.

## Относительное время

`startTime` и `endTime` принимают абсолютное локальное значение, например `2026-07-23T00:00:00`, либо регистронезависимое относительное выражение.

| Основа | Значение |
| --- | --- |
| `NOW` | Текущее локальное время |
| `SECOND`, `MINUTE`, `HOUR` | Начало текущей секунды, минуты или часа |
| `DAY` | Начало текущих суток |
| `WEEK` | Понедельник `00:00` текущей недели |
| `MONTH` | Первое число текущего месяца |
| `YEAR` | 1 января текущего года |

Смещения используют `S`, `M`, `H`, `D`, `W`, `MO` и `Y`. Несколько смещений применяются слева направо. В URL кодируйте знак плюса как `%2B`, потому что неэкранированный `+` преобразуется в пробел.

| Выражение | Значение |
| --- | --- |
| `DAY` ... `DAY%2B1D` | Полные текущие сутки |
| `DAY-1D` ... `DAY` | Полные предыдущие сутки |
| `NOW-8H` ... `NOW` | Последние восемь часов |
| `MONTH-1MO` ... `MONTH` | Предыдущий календарный месяц |

## Приоритет и XML

Приоритет конфигурации при открытии представления:

1. Прямые параметры URL.
2. Соответствующие параметры `View.Args`.
3. Последняя конфигурация, сохранённая в этом браузере для текущего `viewID`.
4. Значения по умолчанию.

Относительные выражения пересчитываются при каждом открытии настроенного представления. В XML заменяйте разделитель параметров `&` на `&amp;`.

```xml
<Args>cnlNums=101,103-108&amp;archiveCode=Min&amp;startTime=DAY&amp;endTime=DAY%2B1D&amp;trendType=line&amp;legendPosition=right&amp;navigationStep=1&amp;navigationUnit=d&amp;navigationMode=shift</Args>
```

Не копируйте числовой `ViewTypeID` из другого проекта. Выберите зарегистрированный тип `TrendJP` в Администраторе, потому что каждая база конфигурации назначает собственный числовой идентификатор.

## Готовые примеры

Замените номера каналов в примерах на каналы, доступные текущему пользователю.

Последние восемь часов с маркерами:

```xml
<Args>cnlNums=101,103-108&amp;archiveCode=Min&amp;period=8h&amp;trendType=line-markers&amp;legendPosition=top</Args>
```

Два архивных источника:

```xml
<Args>multiArchive=true&amp;source1Archive=Cur&amp;source1CnlNums=101,103-105&amp;source2Archive=Min&amp;source2CnlNums=101,103-108&amp;period=8h&amp;legendPosition=right</Args>
```

Оперативный тренд за 30 секунд без элементов управления:

```xml
<Args>cnlNums=101,103&amp;archiveCode=Cur&amp;period=30s&amp;trendType=line-markers&amp;showToolbar=false&amp;showTimeline=false&amp;autoRefresh=true&amp;refreshInterval=1</Args>
```
