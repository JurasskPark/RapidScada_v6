# PlgTrendJP — Main Page Controls

[Contents](index.md) · [Product](../../README.md) · [Русский](../ru/main-page-controls.md)

| Control | Purpose |
| --- | --- |
| **Channels** | Opens channel selection. The licensed `CountTags` value limits the number of unique channel numbers. |
| **Archive** | Selects current, minute, hourly, daily or another configured archive. |
| **Multiple archives** | Enables up to four independently configured archive sources. |
| **From**, **To** | Defines the loaded local time range with second precision. |
| **Timer** | Selects `Auto` or a fixed refresh interval. **Start** and **Stop** control periodic refresh. |
| **Tooltip** | Switches between the nearest channel and all channels at the cursor time. |
| **Refresh** | Reads data for the dates currently shown in the calendar fields. |
| **Reset Zoom** | Restores the complete loaded time range. |
| **Actions** | Opens chart type, display settings, profiles and Excel export. |
| **Timeline** | Shows the complete loaded period and the currently visible window. |
