# PlgMimControlsJP — Первая команда без обратной связи

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/first-command-without-feedback.md)

Отсутствие входных данных отображается явно и обычно не мешает осознанно отправить первую команду:

| Компонент | Доступное действие |
| --- | --- |
| `ComboBox`, `RadioButtonGroup` | Выбрать настроенное значение |
| `CheckBox`, `SquareToggle` | Первое нажатие отправляет `1` |
| `LatchedButton` | Первое нажатие отправляет команду включения |
| `NumericUpDown` | Ввести число или выполнить шаг от минимума |
| `DiscreteSlider` | Выбрать любое настроенное деление |
| `IlluminatedButton`, `TextCommandInput` | Отправить явно настроенную команду |
| `ValueForm` | Изменить и отправить обычные строки |
| `SetpointControl` | Ввести и явно отправить корректную уставку |
| `ModeSelector`, `SearchableComboBox` | Выбрать доступный вариант с учётом настроенных разрешений |
| `MomentaryButton`, `MechanismPanel` | Отправить настроенную команду с учётом прав на канал и разрешений |
| `OneShotButton` | Заблокирован до достоверного сигнала готовности |
| `BitCheckList` | Заблокирован до первой корректной исходной маски |
