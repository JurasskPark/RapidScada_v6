# PlgMimControlsJP — Каталог компонентов

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/component-catalog.md)

Следующие девятнадцать типов являются обычными компонентами. Для их редактирования локальная лицензия компонента не нужна; исполнение в runtime лицензируется.

| Имя типа | Русское название | Размер | Назначение |
| --- | --- | --- | --- |
| [`BitCheckList`](selection-controls.md) | Список битов | `170 × 110` | Изменение выбранных битов без потери скрытых |
| [`CheckBox`](selection-controls.md) | Флажок | `140 × 32` | Двоичная команда `0 / 1` |
| [`ComboBox`](selection-controls.md) | Выпадающий список | `160 × 34` | Выбор одного числового значения |
| [`DiscreteSlider`](numeric-input-and-slider.md) | Дискретный ползунок | `280 × 82` | Выбор точного деления |
| [`IlluminatedButton`](command-buttons.md) | Кнопка с подсветкой | `140 × 64` | Одна фиксированная команда и индикация обратной связи |
| [`LatchedButton`](command-buttons.md) | Фиксируемая кнопка | `130 × 42` | Двухпозиционная командная кнопка |
| [`MechanismPanel`](command-buttons.md) | Панель механизма | `130 × 32` | Кнопка или активная область открытия панели состояния и команд |
| [`ModeSelector`](selection-controls.md) | Переключатель режимов | `220 × 160` | Прямой выбор режима; по умолчанию поворотный переключатель на три положения |
| [`MomentaryButton`](command-buttons.md) | Кнопка удержания | `112 × 32` | Отдельные команды нажатия и отпускания |
| [`NumericUpDown`](numeric-input-and-slider.md) | Числовой ввод | `140 × 36` | Проверяемый числовой ввод и команды шага |
| [`OneShotButton`](command-buttons.md) | Однократная команда | `112 × 32` | Одна команда с ожиданием цикла готовности ПЛК |
| [`ProcessValue`](read-only-components.md) | Текущее значение | `160 × 42` | Форматированное значение только для чтения |
| [`RadioButtonGroup`](selection-controls.md) | Переключатели | `160 × 64` | Наглядный выбор одного значения |
| [`SearchableComboBox`](selection-controls.md) | Выбор с поиском | `240 × 32` | Выпадающий список или список с поиском; исходный размер ListBox `240 × 110` |
| [`SetpointControl`](numeric-input-and-slider.md) | Уставка процесса | `390 × 36` | Раздельные факт, принятая уставка и явный ввод задания; по умолчанию Inline |
| [`SquareToggle`](selection-controls.md) | Квадратный переключатель | `60 × 30` | Компактный квадратный переключатель |
| [`StateIndicator`](read-only-components.md) | Индикатор состояния | `140 × 64` | Лампа состояния только для чтения |
| [`TextCommandInput`](command-input.md) | Ввод команды | `250 × 36` | Ввод числа, UTF-8 или Hex-команды |
| [`ValueForm`](multi-value-form.md) | Форма ввода значений | `210 × 44` | Многострочная модальная форма ввода |

Отдельный демонстрационный тип доступен без лицензии исполнения компонента. В штатном режиме проектирования он предлагается вместе с обычными элементами независимо от серверной лицензии. Сохранённые демонстрации работают как в лицензированном, так и в нелицензированном runtime.
