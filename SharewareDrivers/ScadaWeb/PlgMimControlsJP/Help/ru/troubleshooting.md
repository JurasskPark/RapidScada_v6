# PlgMimControlsJP — Устранение неполадок

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/troubleshooting.md)

| Признак | Причина и действие |
| --- | --- |
| Группа отсутствует в редакторе | Проверьте регистрацию плагина, согласованные DLL, словари и статические ресурсы, затем перезапустите хост. Лицензия исполнения компонента не скрывает палитру проектирования. |
| Компоненты runtime показывают сообщения о лицензии | Проверьте серверный файл `PlgMimControlsJP_License.bin`, `AppName` продукта, UID, срок действия и зависимости лицензирования; после установки ключа перезапустите SCADA Web. |
| Запрос активации `PlgMimControlsJP_Activation.bin` не создаётся | Проверьте `LicenseJP.Logic.dll` и пакетные зависимости рядом со средой плагина, а также право хоста на запись в папку лицензий. |
| В редакторе меньше 19 обычных типов | Проверьте, что DLL, словари и браузерные ресурсы относятся к одному текущему пакету. `ControlsDemo` является дополнительным пунктом и может отсутствовать в лицензированной палитре. |
| Данные видны, но команда не отправляется | В редакторе команды запрещены. Во время выполнения проверьте `Enabled`, право управления, `OutCnlNum` и разрешение команд выходного канала. |
| Команда принята, но вид не изменился | До обратной связи это ожидаемо. Проверьте `InCnlNum` и возврат состояния устройством. |
| Рамка ожидания не видна | Проверьте `Показывать рамку ожидания` и её цвет: исходная настройка зависит от компонента. Рамка видна только во время ожидания команды. |
| `BitCheckList` заблокирован | Не получена достоверная целая неотрицательная маска. Проверьте входной канал и качество. |
| Пустой выбор, неопределённый флажок или `#.#` | Входной канал равен нулю, отсутствует, имеет плохое качество или неподдерживаемое значение. |
| Число отклоняется | Проверьте минимум, максимум, отрицательные значения, точность и соответствие шагу. Экспоненциальная запись не принимается. |
| Текстовая или Hex-команда отклоняется | Проверьте формат. Для Hex нужны пары допустимых шестнадцатеричных цифр без `0x`. |
| Строка `ValueForm` не отправляется | Общая кнопка отправляет только изменённые и корректные строки. Проверьте выходной канал строки, результат проверки и права. |
| `OneShotButton` остаётся заблокированным | Проверьте достоверный цикл готов → не готов → готов. Подтверждение сервера и тайм-аут не подтверждают завершение ПЛК. |
| `SetpointControl` сохраняет прежнюю принятую уставку | Проверьте `SetpointInCnlNum`; команду подтверждает только совпавшая достоверная обратная связь этого канала. Факт и подтверждение транспорта независимы. |
| Классический Администратор сообщает об ошибке загрузки | Установите соответствующий пакетный `PlgMimControlsJP.View.dll`. Он собран с `ScadaWebCommon.Subset` для совместимости с классическим Администратором. |
| Установлены новые файлы, но остался старый вид | Перезапустите приложение или IIS и выполните жёсткое обновление страницы. |
