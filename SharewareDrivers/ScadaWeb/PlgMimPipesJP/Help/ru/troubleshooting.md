# PlgMimPipesJP — Устранение неполадок

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/troubleshooting.md)

| Признак | Причина и действие |
| --- | --- |
| Нет группы **ТРУБОПРОВОДЫ** | Проверьте включение плагина, наличие `PlgMimPipesJP.bin` в папке лицензий текущего приложения и выполните перезапуск. |
| В журнале указано, что лицензия не для этой копии | UID не соответствует компьютеру либо использован запрос активации от другой системы. |
| В журнале указано несовпадение имени приложения | Пересоздайте лицензию с точным именем `PlgMimPipesJP`; имя по умолчанию, например `Demo`, отклоняется. |
| Запрос активации не создаётся | Проверьте права записи в `config` или `License`, журнал плагина и наличие поставляемого модуля лицензирования. |
| Ручные компоненты работают, но авторасстановка недоступна | Откройте мнемосхему в Mimic JP Editor и установите соответствующую версию `PlgMimicJP`. В оригинальном редакторе авторасстановка намеренно отключена. |
| Оборудование всегда показывает неизвестное состояние | Проверьте номер входного канала, его статус и значение. Канал с `stat <= 0` считается недостоверным. |
| Установлены новые файлы, но интерфейс не изменился | Перезапустите приложение или сайт IIS, затем выполните жёсткое обновление страницы. |
