# PlgMimPipesJP — Состояния оборудования

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/equipment-states.md)

Насос, задвижка и манометр получают состояние через стандартную привязку входного канала. Состояние вычисляется во время работы и не выбирается вручную.

## Насос и задвижка

| Данные канала | Отображение |
| --- | --- |
| `stat <= 0`, канал отсутствует или значение нечисловое | Неизвестно: жёлто-оранжевый индикатор |
| `value = 0` | Выключено: красный индикатор |
| `value = 1` | Работает: зелёный индикатор; насос анимирован |
| `value = -1` или `value = 2` | Авария: мигающий красный индикатор |
| любое другое значение | Неизвестно: жёлто-оранжевый индикатор |

Состояние оборудования отображается только на маховике задвижки и двигателе насоса. Корпус трубы сохраняет выбранный цвет.

## Манометр

| Данные канала | Отображение |
| --- | --- |
| `stat <= 0`, канал отсутствует, `NaN` или отрицательное значение | Неизвестно: корпус остаётся видимым, шкала скрывается |
| `value = 0` | Нулевое состояние с неподвижной стрелкой |
| `value > 0` | Активное состояние с белым циферблатом и коротким повторяющимся движением стрелки |

Текущая реализация манометра показывает нулевое, активное или неизвестное состояние. Числовое значение давления не используется как пропорциональное положение стрелки на шкале.
