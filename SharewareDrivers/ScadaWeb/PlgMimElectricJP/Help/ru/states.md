# PlgMimElectricJP — Справочник состояний и миграция

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/states.md)

Состояние 96 типов зависит от канала; пять типов статичны: `ElectricalEarthPE`, `ElectricalEarthFunctional`, `ElectricalCurrentTransformer`, `ElectricalVoltageTransformer` и `ElectricalTerminalBlock`.

Для типа с каналом достоверные данные означают присутствующее конечное числовое значение и конечный числовой статус больше нуля. Числовые строки, отсутствующие значения и неположительный статус не считаются достоверными. Они дают `Unknown`, а не нормальное нулевое состояние.

| Профиль состояния / кодирование | Соответствие достоверных значений |
| --- | --- |
| `Energy` | 0 → `Deenergized`; остальные → `Energized` |
| `IecDoublePoint / Iec61850` | 0 → `Intermediate`; 1 → `Open`; 2 → `Closed`; остальные → `Unknown` |
| `IecDoublePoint / Legacy` | 0 → `Open`; 1 → `Closed`; −1 или 2 → `Trip`; 3 → `Intermediate`; остальные → `Unknown` |
| `Protection` | 0 → `Normal`; остальные → `Alarm` |
| `Operating` | 0 → `Off`; 1 → `On`; 2 → `Intermediate`; 3 → `Alarm`; остальные → `Unknown` |
| `Binary` | 0 → `Off`; остальные → `On` |
| `Contact` | 0 → `Normal`; остальные → `Actuated` |
| `Selector2` | 0 → `Position0`; 1 → `Position1`; остальные → `Unknown` |
| `Selector3` | 0 / 1 / 2 → `Position0` / `Position1` / `Position2`; остальные → `Unknown` |
| `Lamp` | 0 → `Off`; 1 → `On`; −1 или 2 → `Alarm`; остальные → `Unknown` |
| `Analog` | Достоверное число → `Normal` и отображаемое значение |
| `None` | Всегда `Preview`; состояние не зависит от канала |

Приведённые идентификаторы — сохраняемые контракты состояний; интерфейс показывает локализованные названия. Редактор документа использует `Preview` независимо от текущих данных. Средство отображения предоставляет позиционное обозначение, локализованное состояние и аналоговое значение как доступное имя.

## Двухпозиционное состояние и защита

Новые компоненты положения используют `positionEncoding = Iec61850`. При таком кодировании значение 3 означает неизвестное состояние, а не срабатывание защиты. У автомата и УЗО срабатывание поступает с отдельного [входа защиты](channels.md). Ненастроенный вход защиты ничего не переопределяет. Настроенный вход с недостоверными данными даёт `Unknown`; подтверждённое ненулевое срабатывание имеет приоритет над положением и аварией.

## Сохранённые мнемосхемы

Текущая `stateSchemaVersion` — 3. Компоненты, сохранённые без схемы положения, сохраняют кодирование `Legacy`. Старые пассивные символы сохраняют консервативное значение `stateProfileEnabled`; у новых типов с каналом профиль состояния включён.

Миграция сохраняет номера каналов и существующие привязки свойств. `runtimeState`, `runtimePrimaryState`, `runtimeTripState` и `runtimeValue` временные и в `.mim` не записываются. Перед переключением старого автомата на `Iec61850` соответственно измените кодирование исходного канала и проверьте каждое положение.
