# PlgMimElectricJP — Установка

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/installation.md)

Используйте полный переносимый пакет для соответствующей ветки Rapid SCADA. Штатный пакет содержит каталог `SCADA`; при копировании в установленную систему сохраняйте его структуру.

| Место назначения в пакете | Содержимое |
| --- | --- |
| `ScadaWeb/` | `PlgMimElectricJP.dll`, совместимые зависимости и метаданные пакета |
| `ScadaWeb/lang/` | `PlgMimElectricJP.en-GB.xml` и `PlgMimElectricJP.ru-RU.xml` |
| `ScadaWeb/wwwroot/plugins/MimElectricJP/` | JavaScript, стили и изображения символов |
| `ScadaAdmin/Lib/` | `PlgMimElectricJP.View.dll` для классического Администратора |

1. Остановите обновляемый экземпляр Вебстанции и скопируйте полный пакет в его каталог SCADA.
2. Зарегистрируйте и включите `PlgMimElectricJP` в конфигурации плагинов Вебстанции, затем передайте конфигурацию работающему хосту.
3. Если используете классический Администратор, установите модуль представления из того же пакета на рабочее место редактора.
4. Настройте [дополнительные группы](configuration.md) и установите [лицензию исполнения](activation.md).
5. Перезапустите Вебстанцию. Заново откройте редактор и обновите ресурсы браузера.

Не устанавливайте только основную DLL. Пакет включает LicenseJPLite с зависимостями, совместимую `PlgMimic.Common.dll`, словари и веб-ресурсы. Сгенерированный `js/zz-runtime-license.js` необходим для исполнения без лицензии. При его отсутствии обычные типы этого плагина не регистрируются.

Базовый путь ресурсов браузера — `/plugins/MimElectricJP`, а не `/plugins/PlgMimElectricJP`. На системах с чувствительностью к регистру сохраняйте регистр файлов и каталогов.

Эта инструкция описывает штатный переносимый пакет. Для браузерного JP-редактора нужны регистрация и пакет соответствующего хоста; пути другого плагина или старого выпуска не следует подставлять. Точка входа упаковки исходников описана в [сборке](build.md).
