# PlgMimElectricJP — Дополнительные группы палитры

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/configuration.md)

Шесть групп всегда доступны в редакторе. Группы `fire`, `security` и `communications` дополнительные и по умолчанию скрыты.

Создайте `ScadaWeb/config/PlgMimElectricJP.xml`. Этот пример включает только пожарную автоматику:

```xml
<?xml version="1.0" encoding="utf-8"?>
<PlgMimElectricJP>
  <Packages>
    <Package id="fire" enabled="true" />
    <Package id="security" enabled="false" />
    <Package id="communications" enabled="false" />
  </Packages>
</PlgMimElectricJP>
```

Установите `enabled="true"` для каждой нужной дополнительной группы, затем перезапустите Вебстанцию и заново откройте редактор. Распознаются только эти три идентификатора дополнительных пакетов; сравнение не зависит от регистра. Логические значения задаются как `true` или `false`.

Если файла нет, все три дополнительные группы скрыты. При ошибке загрузки плагин пишет её в журнал и использует те же значения по умолчанию. Внешние сущности XML и DTD запрещены.

Переключатели управляют только видимостью групп палитры. Фабрики и средства отображения всех 101 типа остаются зарегистрированными, поэтому отключение группы не удаляет её компоненты из сохранённых мнемосхем. Для обычного исполнения компонентов включённой группы также нужна серверная лицензия.

В хосте с собственной конфигурацией компонентов используйте настройки интеграции этого хоста; указанный выше путь относится к конфигурации Вебстанции.
