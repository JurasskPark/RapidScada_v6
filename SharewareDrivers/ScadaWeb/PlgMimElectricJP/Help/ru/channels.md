# PlgMimElectricJP — Привязки каналов

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/channels.md)

Основной вход состояния — `inCnlNum`. Настройте входной канал с числовым значением и положительным статусом данных. У обычных электрических компонентов нет встроенного командного действия.

Только у `ElectricalBreaker` и `ElectricalRcd` свойство `outCnlNum` означает **независимый вход срабатывания защиты, доступный только для чтения**. Несмотря на унаследованное имя свойства, это не канал выходной команды. Корректный ноль означает норму, ненулевое значение — срабатывание. Если настроенный вход защиты не имеет достоверных данных, итоговое состояние неизвестно, пока отдельная аварийная привязка не переопределит его.

Дополнительные роли настраиваются через `propertyBindings`:

| Свойство | Назначение |
| --- | --- |
| `feedbackValue` | Обратная связь состояния, если основной вход не настроен |
| `alarmValue` | Конечное ненулевое связанное значение заменяет обычное состояние аварией |
| `measurementValue` | Резервная аналоговая обратная связь и отображаемое измерение |
| `commandValue` | Сохраняемые привязываемые сведения; команду не отправляет |

Настроенный основной канал имеет приоритет над дополнительной обратной связью, даже если сейчас его данные отсутствуют или недостоверны. Без основного входа используется настроенная привязка обратной связи; аналоговые типы могут использовать привязку измерения. Срабатывание защиты имеет высший приоритет; авария не заменяет подтверждённое срабатывание. В остальных случаях аварийная привязка может заменить итоговое состояние.

При отображении аналогового значения сначала используется достоверный связанный `measurementValue`. Иначе выводится форматированное `dispVal` основного канала, затем его числовое значение. Отсутствующие или недостоверные данные показываются как `?`.

Привязки сохраняются, а подписки на каналы создаются хостом до обновлений клиента. Изменение профиля состояния не очищает существующие привязки. Общие настройки действия по щелчку, команд, прав, мигания и оформления скрыты описателем; фабрика отключает встроенное командное поведение.

См. [таблицы состояний](states.md) и [примеры автомата и измерения](examples.md).
