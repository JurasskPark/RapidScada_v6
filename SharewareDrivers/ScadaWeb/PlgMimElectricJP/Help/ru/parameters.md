# PlgMimElectricJP — Справочник параметров

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/parameters.md)

Эти свойства относятся к обычным электрическим символам. Общие свойства идентификатора, положения, видимости и всплывающей подсказки предоставляет хост мнемосхем.

| Свойство | Назначение и начальное значение |
| --- | --- |
| `inCnlNum` | Вход состояния; ноль означает отсутствие настройки. У статичных типов скрыт |
| `outCnlNum` | Вход защиты только для чтения у автомата и УЗО; ноль означает отсутствие настройки |
| `propertyBindings` | Дополнительные привязки обратной связи, аварии, измерения и сохраняемого значения команды |
| `rotation` | Deg0, Deg90, Deg180, Deg270; по умолчанию Deg0 |
| `nominalVoltage` | Текст номинального напряжения; начальное значение зависит от типа, иначе пустое |
| `currentSystem` | Unspecified, Ac, Dc; начальное значение зависит от типа |
| `phaseCount / poleCount` | Целое число фаз и полюсов; 0 означает отсутствие сведений; полюса не перерисовываются |
| `signalType` | Перечисление сигналов ниже; начальное значение зависит от типа |
| `cableType` | Перечисление кабелей ниже; начальное значение зависит от типа |
| `referenceDesignation` | Позиционное обозначение, например QF1; по умолчанию пустое; входит в доступное имя |
| `address` | Текст инженерного адреса; по умолчанию пустой; это не адрес протокольного драйвера |
| `symbolProfile` | Inherit, GostIndustrial, Iec, ProjectCustom; по умолчанию Inherit |
| `standardReference` | Редактируемое примечание, начальное значение зависит от типа и исходного профиля символов |
| `customSymbolUrl` | Относительный путь или путь от корня того же сайта; по умолчанию пустой; используется для ProjectCustom |
| `feedbackValue / alarmValue / measurementValue / commandValue` | Привязываемые числовые свойства; по умолчанию 0; назначение описано в справке каналов |
| `positionEncoding` | Legacy или Iec61850; видно только у типов положения; новые типы используют Iec61850 |
| `stateSchemaVersion` | Скрытая сохраняемая версия миграции; текущее значение 3 |
| `stateProfileEnabled` | Скрытый сохраняемый признак состояния; включён у новых типов с каналом |
| `electricalSymbolProfile` | Профиль документа, а не свойство компонента; по умолчанию GostIndustrial |

| Значение | Назначение |

| `DryContact` | Сухой контакт |
| `V24Dc` | 24 В постоянного тока |
| `Milliamp4To20` | 4–20 мА |
| `Volt0To10` | 0–10 В |
| `Rtd` | Термосопротивление |
| `Thermocouple` | Термопара |
| `Pulse` | Импульсный |
| `Ethernet` | Сеть Ethernet |
| `Rs485` | Интерфейс RS-485 |
| `FireLoop` | Пожарный шлейф |
| `Custom` | Проектный сигнал |

## Значения типа кабеля

| Значение | Назначение |
| --- | --- |
| `Unspecified` | Не задан |
| `Power` | Силовой |
| `Control` | Управления |
| `TwistedPair` | Витая пара |
| `Shielded` | Экранированный |
| `FiberOptic` | Оптоволоконный |
| `Coaxial` | Коаксиальный |
| `FireResistant` | Огнестойкий |
| `Custom` | Проектный кабель |

Инженерные поля сохраняются как сведения для оформления и проверки соединений, а не автоматического расчёта цепи. В частности, число фаз и полюсов не создаёт дополнительную геометрию. Канальные свойства и дополнительные роли описаны в [привязках](channels.md), числовые кодирования — в [состояниях](states.md).

Пять статичных типов не используют входы текущего состояния. Унаследованное свойство защиты показывается только у автомата и УЗО. Включение профиля состояния и поля миграции обычно управляются фабрикой, а не редактируются вручную.

У `ElectricalDemo` отдельная ограниченная оболочка: идентификатор, положение, размер, включение, видимость и подсказка. Внутренние каналы, скрипты и привязки недоступны; см. [демонстрацию](demo.md).
