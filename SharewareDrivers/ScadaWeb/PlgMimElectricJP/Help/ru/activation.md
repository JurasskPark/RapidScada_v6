# PlgMimElectricJP — Активация

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/activation.md)

Вебстанция загружает лицензию из своего каталога `ScadaWeb/config`. При стандартной установке Windows это `C:\Program Files\SCADA\ScadaWeb\config`; в других установках используется фактический каталог конфигурации Вебстанции.

| Назначение | Точное имя |
| --- | --- |
| Имя приложения | `PlgMimElectricJP` |
| Запрос активации | `PlgMimElectricJP_Activation.bin` |
| Подписанная лицензия | `PlgMimElectricJP_License.bin` |

1. Запустите Вебстанцию с включённым плагином. Если лицензия отсутствует или недействительна, плагин пытается создать запрос активации. Существующий запрос сохраняется.
2. Передайте запрос поставщику лицензии и получите лицензию с тем же UID сервера и точным именем приложения.
3. Сохраните подписанный файл как `PlgMimElectricJP_License.bin` в каталоге конфигурации этого хоста.
4. Перезапустите Вебстанцию: результат проверки лицензии кэшируется на время работы процесса.
5. Откройте сохранённую мнемосхему с обычным компонентом и проверьте журнал сервера и отображаемое состояние.

LicenseJPLite проверяет подпись лицензии, UID, срок действия и имя продукта. Ключ `MimicEditorJP` или другого плагина компонентов не активирует этот продукт. Отсутствующая зависимость или исключение при проверке также запрещают лицензируемое исполнение.

Для редактирования не нужен локальный ключ компонента; локальные запросы активации не создаются. Без действующей серверной лицензии обычные компоненты заменяются локализованными инертными заглушками: их привязки, скрипты, мигание и действия не выполняются. Другие плагины продолжают работать, а `ElectricalDemo` остаётся доступной. Сохранённые файлы мнемосхем не меняются.

Водяной знак JP-редактора управляется отдельной лицензией редактора. В другом серверном хосте с контрактом поставщика лицензии используйте каталог лицензирования, который передаёт этот хост; здесь проверен путь Вебстанции.
