# PlgMimElectricJP — Профили символов

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/symbol-profiles.md)

Свойство документа `electricalSymbolProfile` по умолчанию равно `GostIndustrial`. В JP-редакторе оно выбирается выпадающим списком электрической панели инструментов; в общей таблице свойств документа оно скрыто. У каждого обычного компонента также есть свойство `symbolProfile`, доступное в стандартном редакторе.

| Значение | Назначение |
| --- | --- |
| `Inherit` | Компонент наследует профиль документа |
| `GostIndustrial` | Исходная библиотека промышленных обозначений |
| `Iec` | Проектные варианты, ориентированные на IEC, при их наличии |
| `ProjectCustom` | Проектный символ из `customSymbolUrl` |

Сначала используется явный выбор компонента, затем выбор документа. `Inherit` — вариант компонента, а не профиль документа.

Библиотека содержит 145 SVG-ресурсов: 101 базовый символ, 30 исходных вариантов состояний, восемь базовых вариантов, ориентированных на IEC, и шесть таких вариантов состояний. Альтернативы охватывают показательные типы, а не весь каталог. Сначала выбирается ресурс состояния данного профиля, затем исходный ресурс состояния, базовый ресурс профиля и исходный базовый ресурс. При отсутствии IEC-варианта используется исходная библиотека.

Графика, ориентированная на IEC, — проектный набор обозначений, а не лицензированная графика базы IEC 60617 и не сертификат соответствия. `standardReference` — редактируемое примечание к правилам оформления; оно не проверяет стандарт и не меняет геометрию.

`ProjectCustom` принимает относительный путь или путь от корня того же сайта, например `/plugins/MySymbols/images/pump.svg`. Пустые адреса, адреса `//...` без протокола, пути с начальным обратным слешем и адреса со схемой вроде `https:` или `data:` отклоняются. Если подходящего собственного адреса нет, используется обычный ресурс.

Собственная картинка заменяет изображение символа, но не логику состояния, фиксированный размер плитки и контракт портов. Подготовьте изображение с учётом этих портов и проверьте поворот.
