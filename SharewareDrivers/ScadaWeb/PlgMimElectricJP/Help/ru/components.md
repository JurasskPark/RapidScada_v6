# PlgMimElectricJP — Каталог компонентов

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/components.md)

101 обычный семантический тип в девяти группах. Идентификаторы типов одинаковы в английской и русской версиях.

| Группа | Типов | Видимость палитры |
| --- | --- | --- |
| [Электроснабжение](components-power.md) | 23 | Доступна по умолчанию |
| [Релейно-контакторное управление](components-control.md) | 16 | Доступна по умолчанию |
| [КИПиА](components-instrumentation.md) | 18 | Доступна по умолчанию |
| [ПЛК и ввод-вывод](components-automation.md) | 6 | Доступна по умолчанию |
| [Кабели и соединения](components-cabling.md) | 19 | Доступна по умолчанию |
| [Пожарная автоматика](components-fire.md) | 6 | По умолчанию скрыта |
| [Охрана и контроль доступа](components-security.md) | 6 | По умолчанию скрыта |
| [Связь и промышленные сети](components-communications.md) | 6 | По умолчанию скрыта |
| [Пользовательские компоненты](components-custom.md) | 1 | Доступна по умолчанию |

Отдельная [ElectricalDemo](demo.md) не входит в число 101 типа.

Размеры на страницах групп указаны в фиксированных логических пикселях до поворота. Профили состояния — идентификаторы из [справочника состояний](states.md). Статичный тип использует `None`. Каналы и инженерные свойства описаны в [привязках](channels.md) и [параметрах](parameters.md).

Дополнительные группы включаются [переключателями пакетов](configuration.md). Скрытие группы не отключает её сохранённые компоненты.
