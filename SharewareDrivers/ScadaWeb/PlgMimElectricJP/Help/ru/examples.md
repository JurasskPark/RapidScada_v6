# PlgMimElectricJP — Примеры настройки

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/examples.md)

Номера каналов ниже приведены для примера. Создайте или выберите реальные входные каналы проекта; каждое проверяемое значение должно иметь положительный достоверный статус данных.

## Положение автомата и независимая защита

Разместите `ElectricalBreaker` и задайте:

| Свойство | Значение |
| --- | --- |
| `referenceDesignation` | `QF1` |
| `inCnlNum` | `1001` |
| `positionEncoding` | `Iec61850` |
| `outCnlNum` | `1002` |

Канал 1001: 0 — промежуточное положение, 1 — разомкнуто, 2 — замкнуто, 3 — неизвестно. Канал 1002: 0 — защита не сработала; любое достоверное ненулевое значение — срабатывание. Например, положение 2 и защита 1 показывают `Trip`. Команда SCADA через 1002 не отправляется.

## Аналоговое измерение

Разместите `ElectricalPressureTransmitter`, задайте `referenceDesignation = PT1`, `inCnlNum = 1010` и `signalType = Milliamp4To20`. Компонент использует значение канала и его формат отображения. Инженерное преобразование и единицы измерения настройте в SCADA; выбор `Milliamp4To20` — инженерные сведения, он не масштабирует измерение.

Для отображения другого вычисляемого измерения привяжите `measurementValue` в редакторе привязок свойств хоста. При достоверных данных это значение имеет приоритет для отображаемого числа. Отсутствующее значение даёт `?`, а не вымышленный ноль.

## Проектный символ

Разместите `ElectricalCustomDevice`, задайте `symbolProfile = ProjectCustom` и `customSymbolUrl = /plugins/MySymbols/images/pump.svg`. Установите SVG по соответствующему пути на том же сайте. Сохраните плитку типа размером 100 × 50 пикселей и его объявленные порты. Проверьте загрузку и поворот в просмотрщике.

## Дополнительная пожарная группа

Используйте XML из [настройки дополнительных групп](configuration.md), затем разместите `ElectricalSmokeDetector`. Его профиль состояния `Protection` связывает достоверный 0 с `Normal`, а достоверное ненулевое значение с `Alarm`. Видимость группы и активация исполнения — независимые настройки.
