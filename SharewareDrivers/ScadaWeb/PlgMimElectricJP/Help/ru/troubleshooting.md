# PlgMimElectricJP — Диагностика

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/troubleshooting.md)

| Признак | Проверка |
| --- | --- |
| Обычный символ показывает сообщение о лицензии | Проверьте каталог конфигурации сервера, точные имена продукта и ключа, UID, срок и зависимости LicenseJPLite; перезапустите Вебстанцию. Редактирование и демонстрация могут работать при заблокированном исполнении. |
| Нет дополнительной группы | Проверьте PlgMimElectricJP.xml, распознаваемый идентификатор пакета и enabled=true; найдите ошибки XML в журнале. После перезапуска заново откройте редактор. |
| Тип не загружается или символы пустые | Проверьте совместимые Web DLL, View DLL, PlgMimic.Common.dll и полный набор ресурсов. Для исполнения без лицензии также проверьте js/zz-runtime-license.js. |
| SVG возвращает 404 | Проверьте /plugins/MimElectricJP/images/symbols/, регистр имён и версию установленного пакета. Обновите кэшированные ресурсы. |
| Состояние неизвестно | Проверьте конечные числовые данные, положительный статус, номер основного канала и настроенный вход защиты. Недостоверный настроенный основной вход не заменяется резервной обратной связью. |
| Изменились состояния старого автомата | Сравните кодирования Legacy и Iec61850. В Iec61850 значение 3 неизвестно, а защита требует отдельного входа. |
| Вместо аналогового значения знак вопроса | Проверьте привязку измерения и основной вход. Сведения о сигнале не выполняют инженерное преобразование. |
| Собственная картинка не применяется | Выберите ProjectCustom и относительный путь или путь от корня того же сайта; внешние схемы и пути // отклоняются. |
| Размер компонента не изменяется | Плитки обычных символов фиксированы; выберите нужный тип или поверните его. У оболочки демонстрации отдельные правила размера. |
| Демонстрация перестала переключаться после действия | Автоматическая последовательность приостанавливается у выбранного примера. Перезапустите автоматическую демонстрацию для сброса обоих; время переключения продолжает зависеть от местных условий. |

Вебстанция пишет в журнал загрузку конфигурации и состояние лицензии. Инструменты разработчика браузера помогают найти отсутствующие скрипты и изображения, ошибки запросов ресурсов. При сообщении о проблеме укажите версию плагина и пакета, версию хоста и соответствующую запись журнала.
