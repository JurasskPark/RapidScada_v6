# PlgMimElectricJP — License and execution

[Contents](index.md) · [Product](../../README.md) · [Русский](../ru/license.md)

The ordinary component runtime is a commercial licensed product. Creating, editing, copying and saving mimics do not require a local component key. `ElectricalDemo` remains autonomous and available without the product runtime license.

A valid server license permits ordinary state rendering and data bindings within the host's normal access controls. An absent, invalid or failed license check replaces ordinary types with inert localized placeholders. It does not activate commands: the electrical symbols' built-in behavior is read-only.

The signed key is product-specific and server-bound. The `MimicEditorJP` license controls its editor watermark separately. Availability of implementation source or the demo does not activate the commercial runtime.

Obtain the license and its usage conditions from the product's license provider. This repository does not contain a signed runtime key or specify pricing and support terms. [Activation procedure](activation.md)
