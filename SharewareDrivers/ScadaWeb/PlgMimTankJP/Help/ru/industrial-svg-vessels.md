# PlgMimTankJP — Промышленные SVG-ёмкости

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/industrial-svg-vessels.md)

Каждая ёмкость всегда показывает корпус и шильдик. Уровнемер, аварийные метки и приборы по умолчанию выключены и появляются только после включения в свойствах. Жидкость отображается на широкой внешней шкале и в отдельных карточках значений; прозрачная заливка внутри корпуса не рисуется.

## Матрица возможностей ёмкостей

| Ёмкость | Слои | Температура | Давление | Дополнительно |
| --- | ---: | --- | --- | --- |
| `RvsVessel` — РВС | 3 | Одиночная, многоточечная | Да | Аварии |
| `VerticalProcessVessel` — вертикальный аппарат | 3 | Одиночная, многоточечная | Да | Аварии |
| `HorizontalProcessVessel` — горизонтальный аппарат | 3 | Одиночная | Да | Аварии |
| `SiloHopper` — силос или бункер | 1 продукт | Одиночная, многоточечная | Нет | Прямая масса |
| `RectangularClosedTank` — закрытая прямоугольная | 3 | Одиночная | Да | Аварии |
| `OpenBath` — открытая ванна | 1 | Одиночная | Нет | Аварии |
| `SphericalTank` — сферический резервуар | 3 | Одиночная | Да | Аварии |
| `ReactorMixer` — реактор-смеситель | 1 | Одиночная, многоточечная | Да | Состояние привода |

Все типы ёмкостей также поддерживают аварийные уровни `LL/L/H/HH` и независимый канал общей аварии.

## Общие свойства ёмкостей

| Свойство | По умолчанию | Назначение |
| --- | ---: | --- |
| **Название ёмкости** (`vesselName`) | Зависит от типа | Текст на шильдике. |
| **Покрытие корпуса** (`bodyStyle`) | `Tinted` | Выбирает тонируемый корпус или фиксированные стальные градиенты. |
| **Цвет корпуса** (`bodyColor`) | `#748491` | Цвет корпуса в режиме `Tinted`. |
| **Показать уровнемер** (`levelEnabled`) | `false` | Показывает внешнюю шкалу и карточки значений. |
| **Высота ёмкости, м** (`tankHeightMeters`) | `8` | Физическая высота ёмкости. |
| **Мёртвая зона, м** (`deadZoneMeters`) | `0` | Компенсация нижнего осадка. |
| **Знаков уровня после запятой** (`decimalPlaces`) | `3` | Точность уровня от `0` до `6`. |
| **Цвет пустой шкалы** (`emptyColor`) | `#e2e8f0` | Пустая часть внешней шкалы. |
| **Показать аварийные уровни** (`alarmsEnabled`) | `false` | Включает метки и привязки `LL/L/H/HH`. |
| **Общая авария** (`generalAlarmEnabled`) | `false` | Включает независимую общую аварию. |
| **Канал общей аварии** (`generalAlarmInCnlNum`) | `0` | Достоверное ненулевое значение включает аварийную рамку. |
| **Действие по щелчку** (`clickAction`) | Пусто | Стандартное действие мнемосхемы. |

Правила источников слоёв, цветов, мёртвой зоны, переполнения, качества и аварий совпадают с полными уровнемерами. Однослойные ёмкости предоставляют только первый слой.

## Покрытия корпуса

| Стиль | Поведение |
| --- | --- |
| **Тонированный** | Использует `bodyColor`, сохраняя промышленные свет и тень. |
| **Сталь** | Использует фиксированные металлические градиенты исходного SVG. `bodyColor` не перекрашивает стальное покрытие. |

## Давление и одиночная температура

Свойства давления доступны только для типов, отмеченных в матрице:

| Группа | Основные настройки | Превью редактора |
| --- | --- | ---: |
| Давление | `pressureEnabled`, `pressureInCnlNum`, `pressureUnit`, `pressureDecimalPlaces` | `0.62 MPa / МПа` |
| Одиночная температура | `temperatureMode = Single`, `temperatureInCnlNum`, `temperatureUnit`, `temperatureDecimalPlaces` | `54.8 °C` |

Во время выполнения значение настроенного канала заменяет превью. При отсутствии данных или плохом качестве отображается `#.#` вместе с заданной единицей измерения.

## Многоточечная температура

Многоточечный режим доступен для `RvsVessel`, `VerticalProcessVessel`, `SiloHopper` и `ReactorMixer`. Редактируемый список содержит от 1 до 24 элементов `TemperaturePoint`.

Каждая точка содержит:

- `name` — название точки;
- `heightMeters` — физическую высоту установки от дна;
- `inCnlNum` — входной канал.

Карточка температуры выбирает точку, ближайшую к текущему физическому уровню до вычитания мёртвой зоны. При одинаковом расстоянии выбирается нижняя точка. Неизвестный или частичный физический уровень либо плохое качество выбранной точки даёт `#.#` без автоматической подмены другой точкой.

Во время выполнения щёлкните карточку `T`, чтобы открыть таблицу всех точек только для чтения, отсортированную по высоте. В таблице показаны имя, высота, значение и качество. Этот щелчок не запускает общее `clickAction` ёмкости.

## Масса силоса

`SiloHopper` может показывать массу с помощью `massEnabled`, `massInCnlNum`, `massUnit` и `massDecimalPlaces`. Превью редактора равно `42.5 t / т`.

Масса читается непосредственно из канала. Плагин не вычисляет объём, плотность, температурную поправку или расчётную массу.

## Привод реактора

Включите `driveEnabled` и задайте `driveInCnlNum`, чтобы показывать состояние привода реактора.

| Данные канала | Состояние и отображение |
| --- | --- |
| Хорошее качество, значение `0` | постоянный красный двигатель |
| Хорошее качество, значение `1` | зелёный двигатель и вращение мешалки |
| Хорошее качество, значение `2` или `-1` | мигающие красные двигатель и карточка |
| Нет данных, плохое качество или другое значение | янтарный двигатель |

Вращение мешалки и мигание аварии отключаются в редакторе и при системной настройке уменьшения движения.
