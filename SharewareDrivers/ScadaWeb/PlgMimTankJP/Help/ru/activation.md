# PlgMimTankJP — Активация

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/activation.md)

Для активации нужен файл запроса с сервера, на котором работает Вебстанция.

1. Скопируйте библиотеки плагина в папку Вебстанции на сервере.
2. Перезапустите веб-сервис Rapid SCADA.
3. В папке `ScadaWeb\config` автоматически появится файл `PlgMimTankJP_Activation.bin` — запрос активации.
4. Скачайте проект с сервера через Администратор. Файл запроса будет в папке `ScadaWeb\config` скачанного проекта.
5. Отправьте этот файл на почту, указанную в README архива плагина.
6. Полученный файл `PlgMimTankJP_License.bin` положите в папку `ScadaWeb\config` проекта в Администраторе и опубликуйте проект на сервер.
7. Если лицензия подходит этому серверу и успешно проверена, плагин активируется. Откройте мнемосхему в Вебстанции и проверьте работу символа.

Сохраняйте имена файлов без изменений.
