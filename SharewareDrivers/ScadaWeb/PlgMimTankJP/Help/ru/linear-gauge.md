# PlgMimTankJP — Линейная шкала

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/linear-gauge.md)

`LinearGauge` — отдельная зональная шкала только для чтения, использующая стандартный входной канал. Она не является многослойным уровнемером и не вычисляет аварии резервуара.

| Свойство | По умолчанию |
| --- | ---: |
| Стандартный входной канал | `0` |
| **Ориентация** (`orientation`) | `Горизонтально` |
| **Единица измерения** (`unit`) | Пусто |
| **Знаков после запятой** (`decimalPlaces`) | `1` |
| **Минимум** (`minimum`) | `0` |
| **Нижняя граница аварии** (`lowAlarmLimit`) | `10` |
| **Нижняя граница предупреждения** (`lowWarningLimit`) | `20` |
| **Верхняя граница предупреждения** (`highWarningLimit`) | `80` |
| **Верхняя граница аварии** (`highAlarmLimit`) | `90` |
| **Максимум** (`maximum`) | `100` |
| **Цвет рабочей зоны** (`workingColor`) | `#22c55e` |
| **Цвет предупреждения** (`warningColor`) | `#f59e0b` |
| **Цвет аварии** (`alarmColor`) | `#dc2626` |

Границы нормализуются по возрастанию между минимумом и максимумом. При подходящем соотношении сторон смена ориентации заменяет горизонтальный размер превью на удобный вертикальный. Отсутствующие или недостоверные данные отображаются как `#.#`. У компонента нет выходного канала, отправки команд и действия по щелчку.
