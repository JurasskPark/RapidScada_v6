# PlgMimTankJP — Полные многослойные уровнемеры

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/full-layered-level-indicators.md)

`TankV2` рисует слои вертикально снизу вверх. `LayerProgress` рисует их горизонтально слева направо. Оба компонента используют одинаковые расчёты физического уровня, качества, мёртвой зоны, переполнения и аварий.

## Режимы источника слоя

| Режим | Поведение во время выполнения |
| --- | --- |
| **Отключён** | Слой полностью исключается из суммы, аварий и отрисовки. |
| **Статический** | `liquidNLevelMeters` используется как реальное значение. Канал не требуется. |
| **Канал** | Во время выполнения читается `liquidNInCnlNum`, а `liquidNLevelMeters` используется только для превью в редакторе. |

Фиксированный порядок слоёв: `Слой 1`, `Слой 2`, `Слой 3`. Слой 1 находится снизу или слева. Отключённый слой исключается без изменения порядка остальных слоёв.

## Общие свойства

| Свойство | По умолчанию | Назначение |
| --- | ---: | --- |
| **Высота резервуара, м** (`tankHeightMeters`) | `8` | Физическая высота в метрах. Должна быть больше нуля. |
| **Мёртвая зона, м** (`deadZoneMeters`) | `0` | Осадок или неиспользуемая нижняя зона. |
| **Знаков после запятой** (`decimalPlaces`) | `1` | Точность значений от `0` до `6`. |
| **Показать шкалу** (`showScale`) | `true` | Показывает деления и подписи шкалы. |
| **Показать общий уровень** (`showTotalLevel`) | `true` | Показывает скорректированный общий уровень. |
| **Показать общий процент** (`showTotalPercent`) | `true` | Показывает процент полезной высоты. |
| **Показать аварии** (`showAlarms`) | `true` | Включает аварийные метки и привязки внешних аварий. |
| **Показать легенду** (`showLegend`) | `true` для `TankV2`, `false` для `LayerProgress` | Показывает названия, цвета и значения слоёв. |
| **Единицы порогов** (`alarmScale`) | `Percent` | Выбирает пороги в процентах или метрах. |
| **Цвет пустого объёма** (`emptyColor`) | `#e2e8f0` | Цвет незаполненной части. |
| **Цвет предупреждения** (`warningColor`) | `#f59e0b` | Цвет предупреждений `L` и `H`. |
| **Цвет аварии** (`alarmColor`) | `#dc2626` | Цвет аварий `LL`, `HH` и переполнения. |
| **Действие по щелчку** (`clickAction`) | Пусто | Стандартное действие мнемосхемы. Плагин самостоятельно команды не отправляет. |

Для каждого из трёх слоёв доступны свойства:

| Шаблон свойства | Назначение |
| --- | --- |
| `liquidNSourceMode` | Выбирает `Отключён`, `Статический` или `Канал`. |
| `liquidNInCnlNum` | Входной канал режима `Канал`. |
| `liquidNName` | Название в легенде или карточке значения ёмкости. |
| `liquidNColor` | HTML-цвет слоя. |
| `liquidNLevelMeters` | Превью редактора и рабочее значение в режиме `Статический`. |

Уровни превью по умолчанию равны `2 / 3 / 2 м`. Исходные цвета: синий `#0066cc`, коричневый `#5c3a21` и тёмный `#1a1a2e`.

## Оформление TankV2

`TankV2` дополнительно предоставляет:

- `legendPosition`: `Сверху`, `Справа`, `Снизу` или `Слева`; по умолчанию — `Справа`;
- `showBubbles`: независимо включает поднимающиеся пузырьки;
- `animateWaves`: независимо включает движение волн жидкости.

Анимации отключаются в режиме редактирования и при системной настройке уменьшения движения.
