# Rapid SCADA — Установка

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/installation.md)

1. Откройте страницу продукта и тему установки или использования.
2. Проверьте требуемую версию Rapid SCADA, платформу .NET, ОС и архитектуру.
3. Используйте подходящий ZIP из `Releases` либо соберите открытый продукт по его инструкции.
4. Скопируйте содержимое `SCADA` пакета в соответствующие каталоги приложений. Сохраняйте зависимости, языковые файлы и веб-ресурсы.
5. Зарегистрируйте и настройте продукт по его справке.
6. Для лицензируемых продуктов выполните инструкции активации.

Сборка пакетов создаёт ZIP: она не устанавливает модули в работающую SCADA, не перезапускает службы и не меняет пользовательскую конфигурацию. Команды развёртывания отдельных продуктов могут выполнять такие действия; это описано в их справке.
