# Rapid SCADA — Installation

[Contents](index.md) · [Product](../../README.md) · [Русский](../ru/installation.md)

1. Open the product page and its installation or usage topic.
2. Check the Rapid SCADA version, runtime and OS/architecture required by that product.
3. Use a matching ZIP from `Releases`, or build an open-source product according to its build topic.
4. Copy the package's `SCADA` contents into the corresponding application directories. Preserve dependencies, language files and web assets.
5. Register and configure the product as described in its own help.
6. For licensed products, follow the product's activation topic.

Package builds create ZIP files; they do not deploy to a running SCADA installation, restart services or modify user configuration. Product-specific deployment commands may have their own effects, described in the relevant help.
