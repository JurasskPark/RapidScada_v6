Драйверы, модули Сервера, расширения Администратора и плагины Вебстанции для Rapid SCADA 6. Выберите продукт или категорию, чтобы открыть краткие страницы продуктов и подробную справку на своём языке.

## [Открытые драйверы](OpenDrivers/README.ru.md)

| Продукт | Назначение |
| --- | --- |
| [DrvDbImportPlus](OpenDrivers/DrvDbImportPlus_v6/README.ru.md) | Импортирует значения из баз данных и передаёт команды SCADA в запросы БД. |
| [DrvDbDataTransferJP](OpenDrivers/DrvDbDataTransferJP_v6/README.ru.md) | Переносит результаты запросов между базами данных и обновляет теги Rapid SCADA. |
| [DrvDDEJP](OpenDrivers/DrvDDEJP/README.ru.md) | Читает значения серверов DDE для Rapid SCADA в Windows. |
| [DrvDebug](OpenDrivers/DrvDebug_v6/README.ru.md) | Проверяет сценарии связи, разбирает ответы и моделирует значения устройств. |
| [DrvFreeDiskSpaceJP](OpenDrivers/DrvFreeDiskSpaceJP_v6/README.ru.md) | Контролирует свободное место на дисках и выполняет настроенные задачи очистки. |
| [DrvFSTJP](OpenDrivers/DrvFSTJP/README.ru.md) | Подключает газоанализаторы ФСТ-03х и блоки расширения реле к Rapid SCADA. |
| [DrvFtpJP](OpenDrivers/DrvFtpJP_v6/README.ru.md) | Автоматизирует передачу файлов FTP с помощью настраиваемых сценариев задач. |
| [DrvPingJP](OpenDrivers/DrvPingJP_v6/README.ru.md) | Контролирует доступность сетевых устройств с помощью ping-запросов. |
| [DrvTelnetJP](OpenDrivers/DrvTelnetJP_v6/README.ru.md) | Контролирует доступность подключений к настроенным TCP-портам. |
