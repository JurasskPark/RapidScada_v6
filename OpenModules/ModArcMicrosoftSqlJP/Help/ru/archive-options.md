# ModArcMicrosoftSqlJP — Параметры архивов

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/archive-options.md)

| Параметр | Описание |
| --- | --- |
| `UseDefaultConn` | Использовать соединение экземпляра по умолчанию из `ScadaInstanceConfig.xml` |
| `Connection` | Именованное соединение из `ModArcMicrosoftSqlJP.xml` |
| `ReadOnly` | Отключить запись в базу данных |
| `MaxQueueSize` | Максимальное количество элементов в очереди |
| `BatchSize` | Количество элементов, записываемых одной транзакцией |
| `PartitionSize` | Период логической секции для исторического архива и событий |
| `UseMemoryCache` | Кэшировать исторические значения в памяти при чтении |
| `CacheSizeRatio` | Коэффициент размера кэша относительно количества каналов архива |
