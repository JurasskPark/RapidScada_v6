# DrvFSTJP — Обзор

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/overview.md)

`DrvFSTJP` — драйвер связи Rapid SCADA 6.x для газоанализаторов ФСТ-03х.

Реализация основана на [руководстве дополнительных функций ФСТ-03х](../../Dopolnitelnye-funktsii-FST-03h.-Rukovodstvo-polzovatelya.pdf) и использует формат пакета RS232/RS485:

- начало пакета: `0D 0A`;
- байт адреса: младшая тетрада — адрес получателя `0..15`, старшая — адрес отправителя `0..15`;
- байт команды;
- байт длины данных `N`;
- контрольная сумма заголовка: младший байт суммы первых пяти байтов;
- блок данных длиной `N` байтов;
- контрольная сумма данных: младший байт суммы данных, `00` при `N = 0`.

Реализованы команды опроса:

- `0x00` — проверка связи; ответ содержит тип устройства: `01` ФСТ-03В, `02` ФСТ-03м, `03` блок расширения реле;
- `0x01` — состояние ФСТ-03х, код ответа `01` или `02`, длина данных `25`;
- необязательный запрос `0x01` к блокам расширения реле, код ответа `03`;
- команды управления `ResetDevice`, `ResetChannel`, `RelayOn`, `RelayOff`, `RelaySetMask`, `SendFstPacket`.
