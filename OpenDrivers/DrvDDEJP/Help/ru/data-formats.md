# DrvDDEJP — Форматы данных

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/data-formats.md)

| Формат | Поведение |
| --- | --- |
| `Bool` | Принимает `1`, `TRUE`, `ON`, `YES`, `0`, `FALSE`, `OFF`, `NO` |
| `Int16`, `UInt16`, `Int32`, `UInt32`, `Int64`, `UInt64` | Разбирает возвращённый текст как число и записывает в Rapid SCADA |
| `Float`, `Double` | Разбирает дробные числа через invariant, текущую и русскую локаль |
| `Ascii` | Записывает возвращённый текст как ASCII-строку |
| `Unicode` | Записывает возвращённый текст как Unicode-строку |
| `HexString` | В текущей runtime-логике записывает возвращённый текст как ASCII-строку |

Перед декодированием входные значения очищаются от пробелов по краям и завершающих символов `NUL`, CR и LF.
