# DrvFtpJP — Настройки FTP

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/ftp-settings.md)

| Настройка | Русский |
| --- | --- |
| `Name` | Имя профиля подключения, отображаемое в интерфейсе настройки. |
| `Host` | Хост FTP-сервера. Значение по умолчанию в коде: `127.0.0.1`. |
| `Username` | Имя пользователя FTP. |
| `Password` | Пароль FTP, сохраняемый в XML-конфигурации через `ScadaUtils.Encrypt`. |
| `Port` | Порт FTP. Интерфейс использует порт `21`, если включен порт по умолчанию. |
| `FtpDataType` | Тип соединения данных, выбранный в интерфейсе и применяемый к `client.Config.DataConnectionType`: пассивный, пассивный без учета маршрутизации или активный. |
| `EncryptionMode` | Режим шифрования FluentFTP, используемый кодом подключения во время работы. |
| `Encryption` | Значение флажка TLS в интерфейсе. Если включен, форма настройки записывает `EncryptionMode = Explicit`; если выключен, записывает `EncryptionMode = None`. |
| `SshKey` | Текст SSH-ключа может сохраняться интерфейсом, но runtime-код FTP-подключения напрямую его не использует. |
