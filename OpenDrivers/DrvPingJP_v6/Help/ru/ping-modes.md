# DrvPingJP — Режимы ping

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/ping-modes.md)

| Режим | Название | Описание |
| --- | --- | --- |
| `0` | Синхронный | Выполняет ping для включённых тегов и ожидает завершения всех созданных задач. |
| `1` | Асинхронный | Запускает асинхронные ping-запросы включённых тегов и ожидает все операции через `Task.WhenAll`. |
