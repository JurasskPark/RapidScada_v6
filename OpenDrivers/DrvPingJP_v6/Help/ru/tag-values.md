# DrvPingJP — Значения тегов

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/tag-values.md)

| Результат ping | Значение | Статус | Формат |
| --- | ---: | ---: | --- |
| Узел доступен | `1` | `1` | Выкл/Вкл |
| Узел недоступен или имя не распознано | `0` | `0` | Выкл/Вкл |

Драйвер выполняет разрешение имени узла перед ping, если в настройке указан не IP-адрес. Если DNS-имя не удается преобразовать в IP-адрес, тег получает значение `0` и статус `0`.
