# DrvTelnetJP — Настройки тегов

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/tag-settings.md)

| Настройка | XML-элемент | Описание |
| --- | --- | --- |
| Идентификатор тега | `ID` | Внутренний GUID тега. |
| Имя | `Name` | Название тега в конфигурации и имя создаваемого канала. |
| Код | `Code` | Код канала Rapid SCADA для записи значений и создания прототипов каналов. |
| Адрес | `IPAddress` | IP-адрес или DNS-имя. |
| Порт | `Port` | Проверяемый TCP-порт. |
| Таймаут | `Timeout` | Тайм-аут подключения в миллисекундах. |
| Включен | `Enable` | Выключенные теги пропускаются при опросе и создаются как неактивные каналы. |
