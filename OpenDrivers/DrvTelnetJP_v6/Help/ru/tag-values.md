# DrvTelnetJP — Значения тегов

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/tag-values.md)

| Результат проверки | Значение | Статус | Формат |
| --- | ---: | ---: | --- |
| TCP-порт открыт | `1` | `1` | Выкл/Вкл |
| TCP-порт закрыт или истек таймаут подключения | `0` | `1` | Выкл/Вкл |
| Имя узла не удалось распознать | `0` | `0` | Выкл/Вкл |

Драйвер записывает значения по коду канала, если указан `TagCode`. Если код пустой, значения записываются по индексу тега.
