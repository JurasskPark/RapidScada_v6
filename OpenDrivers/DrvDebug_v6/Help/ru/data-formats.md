# DrvDebug — Форматы данных

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/data-formats.md)

| Формат | Поведение |
| --- | --- |
| `Bool` | `0` - false, любой ненулевой первый байт - true |
| `Int16`, `UInt16` | Декодирует 2-байтовое число с выбранным порядком байт |
| `Int32`, `UInt32` | Декодирует 4-байтовое число с выбранным порядком байт |
| `Int64`, `UInt64` | Декодирует 8-байтовое число с выбранным порядком байт |
| `Float` | Декодирует 4-байтовый float с выбранным порядком байт |
| `Double` | Декодирует 8-байтовый double с выбранным порядком байт |
| `Ascii` | ASCII-строка, завершающие `NUL` удаляются |
| `Unicode` | UTF-16 Unicode-строка с учётом порядка байт |
| `HexString` | Сегмент байт преобразуется в hex-текст |
