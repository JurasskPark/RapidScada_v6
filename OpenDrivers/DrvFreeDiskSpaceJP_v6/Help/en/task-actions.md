# DrvFreeDiskSpaceJP — Task Actions

[Contents](index.md) · [Product](../../README.md) · [Русский](../ru/task-actions.md)

| Action | English |
| --- | --- |
| `None` | Only monitors disk space and sets tags. No files are changed. |
| `Delete` | Deletes matching old folders from `Path` until the disk has enough free space. |
| `CompressMove` | Creates a ZIP archive for each matching folder, moves the archive to `PathTo`, then deletes the original folder. |
