# Открытые драйверы

[English](README.md) · [Русский](README.ru.md) · [English help](../Help/en/index.md) · [Русская справка](../Help/ru/index.md)

Драйверы связи с открытыми исходниками.

| Продукт | Назначение |
| --- | --- |
| [DrvDbImportPlus](DrvDbImportPlus_v6/README.ru.md) | Импортирует значения из баз данных и передаёт команды SCADA в запросы БД. |
| [DrvDbDataTransferJP](DrvDbDataTransferJP_v6/README.ru.md) | Переносит результаты запросов между базами данных и обновляет теги Rapid SCADA. |
| [DrvDDEJP](DrvDDEJP/README.ru.md) | Читает значения серверов DDE для Rapid SCADA в Windows. |
| [DrvDebug](DrvDebug_v6/README.ru.md) | Проверяет сценарии связи, разбирает ответы и моделирует значения устройств. |
| [DrvFreeDiskSpaceJP](DrvFreeDiskSpaceJP_v6/README.ru.md) | Контролирует свободное место на дисках и выполняет настроенные задачи очистки. |
| [DrvFSTJP](DrvFSTJP/README.ru.md) | Подключает газоанализаторы ФСТ-03х и блоки расширения реле к Rapid SCADA. |
| [DrvFtpJP](DrvFtpJP_v6/README.ru.md) | Автоматизирует передачу файлов FTP с помощью настраиваемых сценариев задач. |
| [DrvPingJP](DrvPingJP_v6/README.ru.md) | Контролирует доступность сетевых устройств с помощью ping-запросов. |
| [DrvTelnetJP](DrvTelnetJP_v6/README.ru.md) | Контролирует доступность подключений к настроенным TCP-портам. |
