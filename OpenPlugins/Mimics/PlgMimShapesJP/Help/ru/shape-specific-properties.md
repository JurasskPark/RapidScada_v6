# PlgMimShapesJP — Специфические свойства фигур

[Оглавление](index.md) · [Продукт](../../README.ru.md) · [English](../en/shape-specific-properties.md)

| Фигура | Свойство | Описание |
| --- | --- | --- |
| **Polygon** | Режим точек | Авто (правильный многоугольник) или Вручную (произвольные точки) |
|  | Число точек | Количество вершин (2-12) |
| **RoundedRect** | Радиус скругления | Радиус скругления углов |
| **Donut** | Размер отверстия | Размер внутреннего отверстия в процентах (10-90%) |
| **Pie** | Начальный угол | Начальный угол в градусах |
|  | Угол сектора | Угол дуги в градусах |
| **Arrow** | Направление | Направление: Вправо, Влево, Вверх, Вниз |
| **Line** | Ориентация | Ориентация: Диагональная, Горизонтальная, Вертикальная, Произвольная |
|  | X1, Y1, X2, Y2 | Координаты концов линии (в процентах) |
